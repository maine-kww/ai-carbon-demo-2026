# 附件C · 行业扩展包（2027 同步版）

> 配套：`双碳系统改造说明书_给WorkBuddy.md`（第 13 章为采集范围与深度规范）、`附件A_五阶段实施内容库_水泥行业.json`、`附件B_窗口一五阶段问答脚本.json`
> 机读版：`附件C_行业扩展包_2027同步版.json`（可直接合入 `KB_INDUSTRY` / `PARAMS` / `SCOPE_COLLECTION`）
> 核验基准日：2026-10-13

## 0. 使用说明与时效声明（先读）

**这份扩展包解决什么问题**：把「每个行业一套核算边界 + 一套范围清单 + 一套政策依据 + 一套减排途径 + 一套方案模板」配齐，让系统从「只有水泥能用」变成「纳管行业与 2027 前需同步的行业都能用」。

**时效声明（重要）**：

1. 政策部分按截至核验基准日已公开的信息整理；**2026–2027 年的扩容名单、配额分配方案、基准值、CCER 方法学备案、CBAM 实施细则均以官方最新发布为准**。
2. 行业纳管状态用三级标记：`已纳管` / `扩容候选` / `未纳管（非纳管驱动）`。凡标 `扩容候选` 的，是方向性判断，**不得在报告中写成已纳入**。
3. 所有基准值、排放因子是**缺省参考值**，正式核算必须用企业实测或最新官方因子替换，并在报告中标注来源与版本。
4. 本扩展包不含任何未公开数据；涉及企业数据的地方一律留 `待补充` 占位。

**每个行业固定五个维度**：① 组织边界 ② 范围 1/2/3 排放源清单 ③ 政策与针对性优化内容 ④ 减排途径（管理型/工艺型/结构型）⑤ 方案要点（指标、技经、交付物差异、风险）。

## 1. 同步范围与优先级（2027 前要配齐什么）

### 1.1 行业清单与纳管状态

| 序 | 行业 | 全国碳市场状态 | CBAM 覆盖 | 同步优先级 | 同步截止 |
|---|---|---|---|---|---|
| 1 | 电力热力 | 已纳管（首批） | 电力（间接） | P0 | 立即 |
| 2 | 钢铁 | 已纳管（2024 年度起） | 是（首批，含前驱物） | P0 | 立即 |
| 3 | 水泥建材 | 已纳管（2024 年度起） | 是（水泥/熟料） | P0 | 立即 |
| 4 | 有色金属（铝冶炼） | 已纳管（2024 年度起） | 是（铝及制品） | P0 | 立即 |
| 5 | 石化 | 扩容候选 | 暂无（下游拟议方向待核） | P1 | 2026 Q4 |
| 6 | 化工（含氯碱/纯碱/基础化工） | 扩容候选 | 化肥类（氮肥、氨） | P1 | 2026 Q4 |
| 7 | 造纸 | 扩容候选 | 暂无 | P1 | 2027 Q1 |
| 8 | 民航（航空运输） | 扩容候选 | 暂无（欧盟 ETS/CORSIA 并行） | P1 | 2027 Q1 |
| 9 | 化肥 | 未纳管 | 是（氨、硝酸、氮肥） | P0（出口驱动） | 立即 |
| 10 | 氢 | 未纳管 | 是（2026 起正式期） | P1 | 2027 Q1 |

### 1.2 同步节奏（建议）

| 时间 | 动作 |
|---|---|
| 2026 Q4 | 配齐石化、化工的组织边界、范围清单、因子与途径；化肥 CBAM 申报模块上线 |
| 2026 Q4–2027 Q1 | 造纸、民航、氢配齐；跟踪扩容名单官方发布，第一时间更新纳管状态 |
| 2027 Q1 | 全行业跑一遍「行业化完成度检查」（术语无外溢、因子已配齐、基准值已填、措施库已替换） |
| 2027 Q1 前 | CBAM 首次正式申报（修订后 9 月 30 日）所需五行业（水泥、钢铁、铝、化肥、氢）申报模块全部可用 |
| 每季度 | 政策复核（扩容名单、配额方案、基准值、方法学、CBAM 细则） |

### 1.3 其余现有行业（不按碳市场同步）

纺织、食品饮料、电子半导体、汽车零部件、装备制造、物流运输、房地产建筑：**不按碳市场纳管同步**，按「出口/供应链/ESG」驱动做差异化即可（见第 4 节）。风险点是 CBAM 拟议向下游产品扩展（如钢铝制成品），一旦落地，汽车零部件、装备制造、电子将被动受波及，需持续跟踪。

## 2. 通用规则（所有行业共用，先钉死这五条）

### 2.1 组织边界

| 规则 | 说明 |
|---|---|
| 合并方法 | 采用**运营控制权法**为默认口径；若客户集团要求股权比例法，必须在 SOW 中声明并全口径一致 |
| 最小核算单元 | 按行业定：电力=机组，水泥=窑线，钢铁=工序，电解铝=系列/车间，造纸=制浆线/纸机，石化=装置，化工=产品线 |
| 设施纳入四条 | ① 本法人拥有或控制 ② 核算年度内运行 ③ 排放源可识别 ④ 数据可得；不满足需说明 |
| 排除规则 | 排除必须写理由（全年停产、非本年度、已转让等），**不得静默排除** |
| 多厂区/多法人 | 分别核算 + 汇总，**不得跨厂区混算**；集团口径需列明各主体清单 |
| 自备电厂 | 自有发电设施排放计入范围 1；只有外购电才计范围 2 |
| 租赁与外包 | 按控制权判断：控制=范围 1/2；不控制=范围 3 |
| 联产品分摊 | 按质量法/热量法/㶲值法之一，**必须在报告中声明所用法**（石化、化工、造纸高发争议） |
| 边界变更 | 并购、关停、新增产线、工艺改造一律走变更流程：留痕（时间/内容/影响/确认人）+ 重新过对应阶段验收标准 |

### 2.2 范围界定

| 项 | 规则 |
|---|---|
| 范围 1 | 自有或控制排放源的直接排放（燃料燃烧、工艺过程、逸散） |
| 范围 2 | 外购电、热、蒸汽、冷；**双报告**：区域电网法 + 市场法（绿电/绿证须有注销凭证），两者口径都写清 |
| 范围 3 | 15 类逐类判断「纳入/未纳入/不适用」并写原因；按「重大性 + 可获取性」筛选，排除项要声明 |
| 生物质碳 | **单独列示**，按碳中性处理但不得与化石碳混算，须有来源证明与检测数据 |
| 碳信用与绿证 | **不计入范围 1/2 排放量**，只能作为抵销（CCER）或市场法调整项，与排放量分列 |
| 工艺过程排放 | 必须单独识别（碳酸盐分解、阳极消耗与效应、重整制氢、N₂O 等），不得并入燃料燃烧 |
| 逸散排放 | 有则必须识别（煤矿瓦斯、油气甲烷、制冷剂、PFC、SF₆），无则写明「不适用」及依据 |

### 2.3 政策适配机制（每个行业建档五件事）

```
行业政策卡 = {
  纳管状态, 管控年度, 配额方法（强度绩效法/基准线法/历史法）, 
  关键基准值（BP或基准线，含版本与年份）,
  履约节点（核定/发放/清缴时间）,
  CCER可用方向（方法学类别，须按最新备案核实）,
  CBAM适用性（覆盖产品、功能单位、申报节点）,
  其他约束（能耗限额标准、双控、行业规范、错峰/产能置换）
}
```

政策变更时**四处必须同步**：`KB_INDUSTRY.policy` → `PARAMS.benchmark` → 窗口二政策卡片 → 报告第十一章。这是第 9 章联动矩阵的一部分。

### 2.4 减排途径统一三层（跨行业通用框架）

| 层 | 投入量级/周期 | 典型内容 | 适用判断 |
|---|---|---|---|
| **管理型** | 零/低投入，0–6 个月 | 计量与台账完善、运行参数优化、泄漏检测与修复（LDAR）、绿证绿电采购、错峰与调度优化、原料与配料比例优化 | 所有企业，先用这层把"免费减排"拿干净 |
| **工艺型** | 中投入，6–18 个月 | 换热网络与余热回收、电机变频、燃烧优化、设备更新、系统集成、控制自动化 | 有明确单耗缺口、回收期 ≤3 年的先做 |
| **结构型** | 大投入，18 个月以上 | 燃料替代、原料替代、电气化、绿电+储能、短流程/新工艺、CCUS | 与客户战略、政策补贴、投资约束匹配后分期实施 |

每条措施统一字段：`名称 / 适用条件 / 投资区间 / 减排量口径 / 回收期 / 前置数据 / 责任部门 / 风险`（对应措施的"一招一卡"）。

### 2.5 方案模板与技经原则

1. **目标口径**：区分绝对量与强度；基准年与核算边界必须一致，不一致要说明。
2. **不重复计算**：工序间（钢铁）、措施间（余热+节电）、上下游（自发电替代外购电）三重去重，必须在技经表里单列去重说明。
3. **回收期口径**：只计入确定性收益（节能收益、碳成本避免、合规必需）；CCER 收益、未落地补贴不计入主口径，可作敏感性。
4. **不确定性**：给出假设区间与敏感性（能源价格 ±30%、碳价 ±50%）。
5. **参数化**：所有基准值、因子、碳价读 `PARAMS` / `em.ef`，禁止硬编码。

## 3. 逐行业扩展包

### 3.1 电力热力（已纳管）

**组织边界**：以**机组**为最小核算单元；自备电厂并入所属法人；热电联产按热量法分摊（须声明分摊方法）；多电厂分别核算后汇总，集团口径需列明主体清单；涉网设施一般并入所属机组。

**排放源清单**

| 范围 | 排放源 |
|---|---|
| 范围 1 | 燃煤/燃气/燃油锅炉与机组燃烧（发电+供热）、启动与助燃用油、脱硫过程（石灰石-石膏湿法 CaCO₃ 分解）、脱硝还原剂分解（如尿素）、燃气机组甲烷逸散与未燃尽、事故与启停放散 |
| 范围 2 | 外购电（厂用外购、启动电源），一般占比较小 |
| 范围 3 | 类别 1（石灰石、氨、催化剂）、类别 3（燃料上游）、类别 4（燃料运输）、类别 5（灰渣与脱硫石膏处置）、类别 6/7（差旅通勤） |

**政策与针对性优化**

| 项 | 内容（须复核最新文件） |
|---|---|
| 纳管状态 | 全国碳市场首批纳管行业（最早管控年度为 2019–2020 年度），纳管门槛与名单按年度通知 |
| 配额方法 | 发电行业以基准线法为主 + 修正系数；供热部分按供热比折算 |
| 关键指标 | 供电煤耗（gce/kWh）、单位供电碳排放强度（gCO₂/kWh）、机组负荷率 |
| CCER | 抵销上限为应清缴配额量的 5%（沿用碳市场通用规则，以年度通知为准）；可用于方向须按最新备案方法学核实 |
| 其他约束 | 能耗限额（GB 21258 常规燃煤发电机组）、煤电"三改联动"、超低排放改造要求 |
| CBAM | 电力为 CBAM 覆盖品类（间接影响），国内燃煤发电企业出口电力场景有限，主要影响为下游产品碳足迹 |

**减排途径**

- 管理型：煤质与配煤管理、燃烧调整与滑压运行优化、厂用电率管理、机组调度与最小出力优化、掺烧比例优化、绿证采购（范围 2 抵扣）。
- 工艺型：汽轮机通流改造、热力系统疏水与凝结水优化、锅炉受热面改造、风机水泵变频、DCS 与控制优化、空预器密封改造。
- 结构型：供热改造（热电联产/大温差供热）、生物质掺烧与耦合发电、新建风光与储能、CCUS 示范项目、关停服役期满小机组。

**方案要点**

- 核心指标：供电煤耗、厂用电率、单位供电碳排放强度、热电分摊比。
- 技经要点：以「节煤量 × 煤价 + 配额缺口成本」双口径算收益；机组调度变化会同时影响产量与强度，测算须固定负荷假设。
- 交付物差异：**机组级**数据台账（分机组）、热电联产分摊说明、配额盈缺按机组汇总、煤质化验记录（NCV/含硫/灰分）。
- 常见风险：煤质波动导致强度漂移；供热季与非供热季口径混用；启停与助燃油耗漏计；实测煤质频次不足只能标缺省值。

### 3.2 钢铁（已纳管 + CBAM）

**组织边界**：长流程按「焦化—烧结—球团—高炉—转炉—轧钢」分工序核算；短流程（电炉）单独成线；联合企业全流程合并，独立轧钢/独立焦化分别核算；公辅设施（自备电厂、制氧、石灰窑、污水处理）纳入并**按工序分摊**；外购焦炭、外购球团按上游产品处理（避免与自产重复）。

**排放源清单**

| 范围 | 排放源 |
|---|---|
| 范围 1 | 焦炉（焦炉煤气）、烧结与球团（固体燃料 + 碳酸盐分解）、高炉（焦炭与喷吹煤、热风炉）、转炉（铁水预处理、转炉煤气）、轧钢加热炉、石灰窑（如有）、自备电厂、熔剂分解（石灰石/白云石）、逸散（煤气放散、炉顶放散） |
| 范围 2 | 外购电（占比较可观） |
| 范围 3 | 类别 1（铁矿石、废钢、外购焦炭、合金、熔剂）、类别 3（输配损失）、类别 4（原料运入）、类别 9（钢材外运）、类别 10/11（下游加工与使用，视需要） |

**政策与针对性优化**

| 项 | 内容（须复核最新文件） |
|---|---|
| 纳管状态 | 已纳管（2024 年度为第一个管控年度） |
| 配额方法 | 强度绩效法（平衡值 BP 按工序产品设定），首个年度配额与实际排放衔接，后续逐年收紧 |
| 关键指标 | 吨钢碳排放强度、各工序单位产品碳排放、废钢比、自发电率、吨钢综合能耗（kgce/t） |
| CCER | 抵销上限 5% 通用规则；可用于方向以余能利用、煤气发电等类别为主，须按最新备案方法学核实 |
| 其他约束 | 超低排放改造、产能置换与粗钢产量调控、能效标杆水平（GB 21256 等） |
| CBAM | **首批覆盖**，且前驱物（烧结矿、直接还原铁等）纳入核算；功能单位与申报口径按最新实施条例 |

**减排途径**

- 管理型：提高煤气回收率（高炉/焦炉/转炉煤气）、提升废钢比、优化炉料结构与燃料比、能源管理中心（EMS）、减少煤气放散与火炬。
- 工艺型：TRT 与干熄焦（CDQ）优化、烧结余热回收、加热炉蓄热式改造、连铸坯热送热装、风机水泵变频、电机能效升级。
- 结构型：电弧炉短流程替代、氢基竖炉/富氢还原中试、球团替代烧结、绿电替代、CCUS 预研、余热余能发电扩容。

**方案要点**

- 核心指标：吨钢碳排放强度、工序碳强度、废钢比、自发电率。
- 技经要点：措施减排量按**工序口径**拆分，严禁同一份减排量在多个工序重复计入；废钢比提升的减排要与上游铁前工序联动核算。
- 交付物差异：工序级数据台账、废钢比与外购焦炭口径说明、**CBAM 嵌入排放表（含前驱物）**、外购与自产煤气热量口径说明。
- 常见风险：工序间排放分摊争议（必须声明分摊法）；煤气回收与放散量计量缺失；粗钢/钢材产量口径混用；CBAM 前驱物数据链断裂。

### 3.3 水泥建材（已纳管 + CBAM）

**组织边界**：以**熟料生产线（窑线）**为最小核算单元；粉磨站单独或合并需说明；自备矿山（石灰石开采）在范围 1/3 的边界内明确约定；协同处置固废与替代燃料的设施纳入；多窑线企业分别核算后汇总。

**排放源清单**

| 范围 | 排放源 |
|---|---|
| 范围 1 | 熟料煅烧燃料（煤炭、替代燃料）、碳酸盐分解（过程排放，缺省 0.535 tCO₂/t熟料）、替代原料非碳酸盐扣减（须有化验报告）、辅助燃油、烘干热源；水泥行业一般无 SF₆/HFC 逸散 |
| 范围 2 | 外购电（扣除余热自发自用、绿电按市场法且需注销凭证） |
| 范围 3 | 类别 1（石灰石/石膏/混合材、包装袋、耐火材料）、类别 2（设备）、类别 3（电力输配损失）、类别 4（原煤与替代燃料运入）、类别 5/6/7（废弃物、差旅、通勤）、类别 9（水泥外运） |

**政策与针对性优化**

| 项 | 内容（须复核最新文件） |
|---|---|
| 纳管状态 | 已纳管（2024 年度起） |
| 配额方法 | 强度绩效法，平衡值 BP 以吨熟料强度设定（示例 0.88 tCO₂/t熟料，逐年收紧） |
| 关键指标 | 吨熟料碳排放强度、吨水泥碳排放强度、替代燃料热替代率、单位产品综合能耗（kgce/t熟料，能效标杆约 105） |
| CCER | 抵销上限 5%；可用于方向以余热发电、甲烷利用等类别为主，须按最新备案方法学核实 |
| 其他约束 | 错峰生产与产能置换影响实际产量口径；GB 16780 能耗限额；产品碳足迹标准（HJ 征求意见稿、T/CBMF 277-2024） |
| CBAM | 覆盖水泥与熟料（HS 2523 / 252310），**功能单位为吨熟料** |

**减排途径**

- 管理型：替代燃料比例提升、余热发电运行优化、计量与台账完善、错峰与生产组织优化、绿电绿证采购。
- 工艺型：篦冷机改造、预热器与分解炉优化、粉磨系统（辊压机 + 立磨）节能、窑体保温、生料易烧性改善、变频与电机升级。
- 结构型：原料替代（电石渣/钢渣/粉煤灰）、燃料替代（RDF/生物质）、余热发电扩容、分布式光伏 + 储能、CCUS 预研。

**方案要点**

- 核心指标：吨熟料强度、吨水泥强度、替代燃料热替代率、综合能耗。
- 技经要点：以「强度下降带来配额缺口收窄」为主收益线，节能收益为辅；替代燃料测算需同时算燃料价差与减排量。
- 交付物差异：窑线级数据台账、替代原料扣减的化验报告、**CBAM 吨熟料嵌入排放表**、熟料外销记录。
- 常见风险：余热自发电单位换算（万kWh ↔ MWh，10 倍差）；替代原料扣减无化验报告；错峰停产导致产量与产能口径不一致；石灰石单耗异常（是否含替代原料/矿山剥离量）。

### 3.4 有色金属（铝冶炼，已纳管 + CBAM）

**组织边界**：电解铝以**系列/车间**为核算单元；电解铝 + 自备电厂 + 阳极炭素全流程合并时须分别列示并可拆分；氧化铝、铝加工、再生铝按是否同一法人分别核算；自备电厂发电排放计范围 1，外购电计范围 2。

**排放源清单**

| 范围 | 排放源 |
|---|---|
| 范围 1 | **阳极消耗**（炭阳极净耗，按公式法核算）、**阳极效应 PFC**（CF₄/C₂F₆，按 GWP 折算）、燃料燃烧（焙烧炉、自备电厂、煅烧石油焦）、氧化铝生产中的碳酸盐分解与燃料（若同法人）、铝灰处理 |
| 范围 2 | 外购电（电解铝占比极高，常为最大排放源） |
| 范围 3 | 类别 1（氧化铝、预焙阳极、氟化盐、石油焦）、类别 3（输配损失）、类别 4（原料运输）、类别 9（铝锭/铝材外运） |

**政策与针对性优化**

| 项 | 内容（须复核最新文件） |
|---|---|
| 纳管状态 | 已纳管（铝冶炼，2024 年度起） |
| 配额方法 | 强度绩效法，以吨铝碳排放强度设定平衡值 |
| 关键指标 | 吨铝直流电耗（kWh/t）、综合交流电耗、阳极净耗（kg/t）、吨铝碳排放强度、绿电占比 |
| CCER | 抵销上限 5% 通用规则 |
| 其他约束 | 电解铝产能天花板与阶梯电价政策；GB 21346 能耗限额；绿电消费责任权重 |
| CBAM | 覆盖铝及铝制品（按铝含量核算，前驱物纳入），功能单位与申报口径按最新实施条例 |

**减排途径**

- 管理型：电流效率提升、槽电压优化、阳极净耗管理、阳极效应系数控制、绿电绿证采购、整流效率优化。
- 工艺型：电解槽阴极与内衬优化、惰性阳极试点跟踪、阳极效应智能控制、余热回收、铝液直供与短流程衔接。
- 结构型：再生铝比例提升（减排杠杆最大）、绿电直供 + 储能、氧化铝工艺协同、惰性阳极产业化落地后替换。

**方案要点**

- 核心指标：吨铝直流/交流电耗、阳极净耗、吨铝碳排放强度、绿电占比。
- 技经要点：**电耗下降的电费收益通常大于碳收益**，需双口径列示；绿电采购要区分"降本"与"降碳"两条账。
- 交付物差异：吨铝嵌入排放表（CBAM）、绿电消纳与绿证台账、阳极效应台账、PFC 核算说明。
- 常见风险：自备电厂与企业边界的处理；绿电抵扣凭证链断裂；PFC 与阳极净耗计量缺失；再生铝原料来源数据质量差。

### 3.5 石化（扩容候选）

> 纳管状态为方向性判断，**未获官方确认前不得在报告中表述为"已纳入"**。

**组织边界**：以**装置/单元**为核算单元（常减压、催化裂化、加氢、重整、延迟焦化、乙烯裂解、芳烃等）；装置级分摊公辅消耗；自备电厂与动力站纳入（发电排放计范围 1）；储运罐区与装卸纳入逸散核算；炼化一体化企业按装置汇总。

**排放源清单**

| 范围 | 排放源 |
|---|---|
| 范围 1 | 工艺加热炉燃料燃烧、催化裂化再生烟气（催化剂烧焦）、制氢装置（重整 + PSA）、火炬、硫回收、**无组织逸散（甲烷与 VOCs，含设备动静密封点泄漏）**、制冷剂、自备电厂燃料 |
| 范围 2 | 外购电与外购蒸汽（石化用汽量大，蒸汽常为最大间接排放源） |
| 范围 3 | 类别 1（原油与外购原料）、类别 3（输配损失）、类别 4/9（运输）、类别 10（售出产品加工）、类别 11（燃料型产品使用，通常占比极大但常不纳入，须声明） |

**政策与针对性优化**

| 项 | 内容（须复核最新文件） |
|---|---|
| 纳管状态 | **扩容候选**（"十五五"有序扩围方向之一），以官方发布为准 |
| 配额方法 | 尚未确定；参照已纳管行业的强度绩效法方向预置参数位 |
| 关键指标 | 单位能量因数能耗、炼油/乙烯单位产品能耗、吨原料碳排放、加热炉热效率 |
| CCER | 须按最新备案方法学核实；节能技改与余热利用类为主 |
| 其他约束 | 能耗双控与碳排放双控衔接、能耗限额标准（炼油、乙烯等）、甲烷排放控制行动方案、VOCs 综合治理、排污许可 |
| CBAM | 石化产品暂未纳入；下游塑料制品为拟议扩展方向，须跟踪 |

**减排途径**

- 管理型：加热炉热效率管理、换热网络优化、蒸汽系统平衡与减压站管理、**LDAR 泄漏检测与修复**、火炬气回收、甲烷泄漏管控。
- 工艺型：高效换热器与空气预热器、变频与电机升级、乏汽与凝结水回收、余热发电、控制与优化系统。
- 结构型：绿电替代、绿氢替代制氢原料、电加热炉（电气化）、CCUS、原料低碳化与轻质化。

**方案要点**

- 核心指标：单位能量因数能耗、乙烯/炼油单位产品能耗、吨产品碳排放、加热炉热效率。
- 技经要点：**加热炉与蒸汽系统优先**（回收期普遍短）；无组织排放减排量难量化，只作定性收益或按计量法折算。
- 交付物差异：装置级数据台账、火炬与无组织排放核算说明、产品碳足迹（化工产品 PCF）叠加。
- 常见风险：装置多口径杂；产品"燃料用"与"原料用"的归类影响范围 3；无组织排放数据可得性差；涉密工艺数据需脱敏。

### 3.6 化工（含氯碱、纯碱、基础化工；扩容候选）

> 纳管状态为方向性判断，**未获官方确认前不得表述为"已纳入"**。

**组织边界**：按**产品线与装置**核算（合成氨、尿素、氯碱、纯碱、硫酸、电石法 PVC、炭黑等分别设定）；联产品与副产品分摊方法必须声明（氯碱的碱与氯、纯碱的联产）；自备电厂纳入。

| 范围 3 | 类别 1（天然气、煤炭、原盐、矿石、电石）、类别 3/4/9、类别 10/11（视产品用途） |

|---|---|

| 配额方法 | 尚未确定；预置强度绩效法参数位 |
| 关键指标 | 单位产品综合能耗（合成氨、烧碱、纯碱、硫酸各有能耗限额标准）、吨产品碳排放、N₂O 分解率 |
| CCER | 以节能技改、余热余压、N₂O 分解等类别为主，须按最新备案方法学核实 |

- 管理型：LDAR 泄漏检测与修复、蒸汽系统与疏水管理、反应条件优化、**N₂O 分解催化剂投运率管理**、副产氢与弛放气回收。
- 工艺型：余热回收（转化气废热锅炉等）、高效压缩机与透平、换热网络优化、电机变频、循环水系统优化。
- 结构型：绿氢替代制氢原料、电气化（电加热/电锅炉）、电石法改乙烯法、原料路线替代、CCUS。

**方案要点**

- 核心指标：单位产品综合能耗、吨产品碳排放、N₂O 分解率、原料单耗。

- 交付物差异：工艺过程排放专项核算（N₂O/碳酸盐/制氢）、CBAM 嵌入排放申报表（化肥类）、危化品数据与碳数据分离管理。
- 常见风险：工艺路线差异巨大（煤头/气头/油头），同一产品碳强度可差一倍以上；产品多、分摊复杂；数据涉密。

### 3.8 民航 / 航空运输（扩容候选）

- 核心指标：吨公里油耗、单位周转量碳排放、SAF 比例。
- 技经要点：**SAF 成本远高于碳价**，测算须分「合规必需」与「成本可行」两条线；减排主要靠运行优化与机队更新。
- 交付物差异：按航线/机型的油耗与排放表（CORSIA 口径）、SAF 采购与可持续认证凭证、欧盟 ETS 与国内碳市场口径对照说明。
- 常见风险：三套国际/国内规则口径混用；外站加油与代码共享航班的归属；SAF 供应与价格波动。

### 3.9 化肥（CBAM 覆盖，出口驱动）

**组织边界**：以**合成氨装置、尿素装置、硝酸装置**分别核算；天然气路线与煤制路线分别列示；自备电厂纳入；氨—尿素一体化企业须处理中间产品转移。

**排放源清单**

| 范围 | 排放源 |
|---|---|
| 范围 1 | **制氢（天然气重整 / 煤气化）**、**硝酸生产的 N₂O**、氨合成回路弛放气与吹除气、尿素水解与造粒干燥燃料、燃料燃烧 |
| 范围 2 | 外购电与外购蒸汽（氨合成用汽量大） |
| 范围 3 | 类别 1（天然气、煤炭）、类别 4/9（运输） |

**政策与针对性优化**

| 项 | 内容（须复核最新文件） |
|---|---|
| 纳管状态 | 国内**未纳管**；受能耗双控与行业能效标杆约束 |
| 配额方法 | 不适用（未纳管） |
| 关键指标 | 吨氨综合能耗（GJ/t）、吨氨碳排放、N₂O 排放因子与分解率 |
| CCER | 须按最新备案方法学核实 |
| 其他约束 | GB 21344（合成氨）等能耗限额、天然气价格与保供政策、化肥行业环保要求 |
| CBAM | **已覆盖**（氨、硝酸、氮肥）；2026 起正式实施期，首次正式申报 2027 年（修订后至 9 月 30 日），功能单位与口径按最新实施条例 |

**减排途径**

- 管理型：**N₂O 分解催化剂投运率**、弛放气回收、蒸汽系统平衡、转化炉运行优化。
- 工艺型：转化气余热回收、机组与压缩机改造、换热网络优化、循环水与冷却系统优化。
- 结构型：绿氢/绿氨路线、原料替代、电气化、CCUS。

**方案要点**

- 核心指标：吨氨综合能耗、吨氨碳排放、N₂O 分解率。
- 技经要点：**碳成本直接影响出口竞争力**（CBAM 证书成本按嵌入排放计），须与出口价格联动测算。
- 交付物差异：**CBAM 嵌入排放申报表（含前驱物）**、N₂O 台账、氨产品碳足迹。
- 常见风险：吨氨嵌入排放取值必须以企业实测为准（不可套用通用值）；煤头与气头差异大；副产 CO₂ 利用（尿素）的归属需声明。

### 3.10 氢（CBAM 覆盖，新兴）

**组织边界**：以**制氢装置**为核算单元（化石重整 SMR、煤气化、电解水）；蓝氢须说明 CCS 边界与捕集率；绿氢须建立绿电凭证链（电量、时段、注销证明）。

**排放源清单**

| 范围 | 排放源 |
|---|---|
| 范围 1 | 重整/气化原料与燃料排放、PSA 尾气、火炬、备用电源；电解水路线基本无范围 1 |
| 范围 2 | 电解水制氢的外购电（**决定绿氢属性**） |
| 范围 3 | 类别 1（天然气、电力、水处理药剂）、类别 3/4/9 |

**政策与针对性优化**

| 项 | 内容（须复核最新文件） |
|---|---|
| 纳管状态 | 国内**未纳管**；受氢能产业规划与可再生能源制氢支持政策影响 |
| 配额方法 | 不适用 |
| 关键指标 | kgCO₂/kgH₂、电耗（kWh/kgH₂）、绿电占比、CCS 捕集率（蓝氢） |
| CCER | 须按最新备案方法学核实 |
| 其他约束 | 氢能产业规划、绿氢绿氨支持政策、可再生能源电力消纳责任权重 |
| CBAM | **已覆盖氢**；2026 起正式实施期，首次正式申报 2027 年，核算细则以最新实施条例为准 |

**减排途径**

- 管理型：负荷与纯度优化、收率管理、泄漏管控、绿电采购组合优化。
- 工艺型：电解槽效率优化、余热回收、压缩与储运能耗优化。
- 结构型：绿电直供 + 储能、电解槽大型化、CCUS（蓝氢）、绿氨合成与下游耦合。

**方案要点**

- 核心指标：kgCO₂/kgH₂、电耗、绿电占比。
- 技经要点：电耗与电价决定成本，**绿电凭证决定"绿色"属性**；两条账分开算。
- 交付物差异：氢属性证明（绿电凭证链 + 电解槽运行数据）、CBAM 嵌入排放表、绿氨产品碳足迹（如延伸）。
- 常见风险：绿氢属性证据链不完整；CBAM 对氢的核算细则仍在演进；绿电时段匹配要求可能升级。

## 4. 其余现有行业的同步结论（不按碳市场同步）

| 行业 | 驱动因素 | 需要行业化的内容 | 优先级 |
|---|---|---|---|

## 8. 怎么进系统（落地方式）

| 要落的地方 | 用本扩展包哪一节 | 具体动作 |
|---|---|---|
| `KB_INDUSTRY` | 3.1–3.10 的「组织边界 + 范围清单」 | 把每行业的 `scope` 升级为排放源清单（范围 1/2/3 分列），新增 `orgBoundary` 与 `minUnit`（最小核算单元）字段 |
| `PARAMS.benchmark` | 第 5 节政策矩阵 | 每行业填 `配额方法 / 关键指标 / 基准值（含版本年份）`，未确定项留 `待官方发布` |
| 政策卡片 | 3.x 的「政策与针对性优化」 | 升级到 L2 可引用级（文号 + 生效状态 + 对企业要求 + 引用章节 + 原文链接） |
| `KB_STAGE_PATCH` | 3.x 的「途径 + 方案要点」 | 按行业写 patch：措施库（`measuresAdd`）、术语替换、红线（`redlinesAdd`） |
| `SCOPE_COLLECTION` | 3.x 的「排放源清单」 | 每行业一份 L2 采集行（沿用 `S1-xx/S2-xx/S3-xx` 编号，行内容行业化） |
| `DELIVERABLE_LIB` / `DEPTH_MAP` | 3.x 的「交付物差异」 | 每行业补 CBAM / 配额 / PCF 等条件章节的字段与档位 |
| 行业完备自检 | 第 1.2 节 | 用 `industryReady()` 按「术语/因子/基准/措施」四项检查，未通过则卡片头提示「该行业内容待完善」 |

**每行业上线前的四项检查（缺一不可）**：术语无外溢（不出现别行业专有名词）、因子已配齐（含来源与版本）、强度基准值已填（或明确标"待官方发布"）、措施库已替换（不套用水泥/钢铁的措施）。
