## 5. 硬约束（违反会被 lint 拦或出线上事故）

1. **单文件、无外部依赖**：不加 CDN，断网可用。
2. **PQ005**：`innerHTML` 只能赋被 `sanitizeHtml` / `esc` 整体包裹的值；一切渲染走 `setHTML()`。
3. **PQ001 + 老坑**：script 体内 `</` 写成 `<\/`；**改完必须校验 `<script>` 开闭标签数量相等**，否则整段 JS 静默不执行。
4. **DSDK002**：`databaseId` 必须是字面量或 `DATABASE_ID` 变量；新表要配 `var DATABASE_ID_x = '...'`。
5. **DSDK008**：含 `addRecord` 的页面必须保留 localStorage 缓存与 `removeItem` 清理。
6. **PQ105/PQ107**：关联数据库要有加载态文案 + 用户可见的 catch 提示。
7. **架构**：数据层 → 计算层 → 渲染层单向；`refreshAll()` 是唯一刷新入口；渲染函数互不调用。
8. **schema 变更前先确认**：新增 select 选项或字段必须同步云端 schema，否则写入失败（表现为"云端写入失败，已转本地暂存"）。
9. **不编造数据**：缺失一律 `待补充` + 缺口清单；缺省值必须标"缺省值"并写未实测原因。
10. **参数不硬编码**：碳价、因子、基准值一律读 `PARAMS` / `em.ef`。
