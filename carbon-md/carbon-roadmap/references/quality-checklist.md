# 企业碳中和路径规划质量检查清单

> **历史参考，以 _data 数据层为准（2026-10-09）**：本文件涉及的核算/披露标准版本、排放因子、配额分配与激励政策等参数，正式使用时一律从 `_data` 数据层（`query.py` 的 query_industry / query_factor / query_policy）动态查询；本文件仅作数据层未命中时的 legacy 回退与背景参考，回退使用时须在输出中标注“legacy 回退”。

## 一、目标与边界
| 检查项 | 通过标准 |
|--------|----------|
| 目标定义清晰 | 明确碳达峰 / 碳中和 / 净零 / SBTi 等目标类型，避免概念混淆 |
| 组织边界一致 | 目标覆盖的组织边界（股权 / 控制权 / 运营边界）与排放核算边界一致 |
| 排放范围明确 | 明确纳入范围 1、范围 2、范围 3，以及范围 3 的类别覆盖度 |
| 基准年选择合理 | 基准年数据完整、有代表性，选择理由充分（正常经营年度、非异常年） |
| 目标年份可达 | 目标年份与行业发展阶段、技术成熟度、政策要求相匹配，不过度激进也不保守 |

## 二、基线与减排测算
| 检查项 | 通过标准 |
|--------|----------|
| 基线排放数据可靠 | 基线排放核算方法符合 GHG Protocol 或 ISO 14064-1 标准，数据来源可追溯 |
| 减排杠杆分类清晰 | 能效、可再生能源、电气化、工艺变革、供应链、碳移除等减排措施分类不重叠 |
| 减排潜力测算有据 | 每项措施的减排量测算有技术依据、行业基准或对标数据支撑 |
| 成本估算透明 | 减排成本（CAPEX / OPEX）有参考来源，关键假设明确列出 |
| 减排时序合理 | 措施落地时间表与技术可行性、投资周期、供应链周期匹配，不违背工程常识 |

## 三、抵消与残余排放
| 检查项 | 通过标准 |
|--------|----------|
| 残余排放定义明确 | 技术 / 经济上不可行减排的部分被明确定义为残余排放，并有判定依据 |
| 抵消比例合规 | 抵消比例与目标类型（碳中和 / 净零）匹配，符合主流标准要求 |
| 抵消工具合规 | 使用的碳信用（CCER / 碳汇 / 国际信用）符合目标声明对应的标准要求 |
| 抵消不重复计算 | 抵消所用减排量未被其他主体或其他目标重复使用 |

## 四、路线图文件
| 检查项 | 通过标准 |
|--------|----------|
| 目标-措施对应关系清晰 | 每项减排措施对总目标的贡献可量化、可追溯 |
| 里程碑设置合理 | 分阶段（近 3 年 / 中期 / 远期）里程碑明确，关键指标可监测 |
| 治理与资源保障 | 组织结构、责任分工、预算安排、能力建设等保障措施有说明 |
| 监测与评估机制 | 排放监测、进度评估、定期修订（如每 3-5 年更新）机制已规划 |
| 风险与不确定性 | 技术风险、政策风险、市场风险有识别，并提出应对预案 |

## 五、合规与声明
| 检查项 | 通过标准 |
|--------|----------|
| 目标标准匹配 | 声明遵循的标准（SBTi / PAS 2060 / ISO 14068 / ISO Net Zero Guidelines）条款基本符合 |
| 减排优先原则 | 遵循"减排优先、抵消补充"原则，不以抵消替代实质性减排 |
| 无漂绿风险 | 对外沟通口径真实、严谨，不夸大减排成效，不使用易误导表述 |
| 外部验证安排 | 如需对外披露或认证，已规划第三方核查或 SBTi 验证等安排 |
