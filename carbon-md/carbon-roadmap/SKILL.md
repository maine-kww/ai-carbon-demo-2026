# Carbon Roadmap  企业碳中和路径规划

## Overview

基于企业排放基线，设定碳达峰/碳中和目标并规划分阶段减排路径，输出可执行的路线图（目标、措施、时间表、资源与抵消策略）。核心逻辑：**排放基线 → 减排杠杆 → 分阶段目标 → 残余排放抵消 → 路线图**。

本 Skill 为**数据驱动模式**：路线图对齐的**行业核算规则、碳市场扩围节点与配额方案、零碳工厂培育行业清单等政策时间表、排放因子**一律从 `data/` 数据层动态查询，不在本文件写死扩围年份/配额规则/因子数值；历史值已下沉到 `references/`（并加注"以数据层为准"）。

## 数据层（路线图对齐前必读）

行业核算规则、碳市场扩围节点与配额方案、零碳工厂培育行业清单等政策时间表、排放因子均从 `data/` 数据层动态查询，**不在本 Skill 中写死扩围年份/配额规则/因子数值**。新增行业或政策更新只需在数据层追加记录。

| 内容 | 数据文件 | 统一查询命令 |
|---|---|---|
| 行业规则表（核算标准、纳入碳市场时间、配额方法） | `data/industry/industry_rules.json` | `python data/scripts/query_data.py get-industry <行业名>` |
| 全部行业列表 | `data/industry/industry_rules.json` | `python data/scripts/query_data.py list-industries` |
| 政策元数据表（配额方案、激励政策、碳达峰方案） | `data/policy/policy_metadata.json` | `python data/scripts/query_data.py search-policy <关键词>` |
| 电网排放因子库 | `data/factors/grid_electricity_factors.json` | `python data/scripts/query_data.py get-grid-factor --year <年份> --region <区域>` |
| 化石燃料因子库 | `data/factors/fossil_fuel_factors.json` | `python data/scripts/query_data.py get-fuel-factor <燃料类型>` |
| 数据版本号 | — | `python data/scripts/query_data.py version` |

> 运行路径：在 `carbon-md/` 根目录下执行上述命令。

数据状态约定：数据层每条记录含 `confidence` 或 `status` 字段，引用时透传，不得把估算/占位当已查证。SBTi、PAS 2060、ISO 14068 等国际净零标准数据层未收录，仍以 `references/roadmap-guide.md` 为背景参考并标注版本以官方最新为准。

## Workflow

### 1. 建立排放基线（确定行业/报告期/地区）
- 引用 `carbon-accounting` 核算当前排放（范围 1/2，以及范围 3 若纳入）；排放因子经 `query_factor()` 查询。
- 确定基准年与边界（组织边界、覆盖范围），作为目标锚点；明确**所在行业**。

### 2. 从行业规则表查询行业规则与扩围节点（get-industry）
- 执行 `python data/scripts/query_data.py get-industry <行业名>`，获取该行业：核算标准、纳入碳市场时间、配额分配方法、是否覆盖间接排放、核查要求。
- 用 `数据层行业规则表顶层元数据` 读取顶层时间线（全国碳市场启动/首次扩围/2026 年状态/2027、2030 目标）与"零碳工厂扩围计划"培育行业清单（2027 年：汽车/锂电池/光伏/电子电器/轻工/机械/算力设施；2030 年拓展：钢铁/有色/石化化工/建材/纺织），据此判断企业行业所处的政策阶段与路线图外部约束。
- 行业不在表中：提示"该行业未纳入碳市场/未建规则"，目标按通用口径（GB/T 32150-2025 通则）设计并标注。

### 3. 从政策元数据表查询政策时间表（search-policy）
- 执行 `python data/scripts/query_data.py search-policy ..., 政策类型=配额方案/激励政策/工作方案...)`，获取：
  - 该行业配额方案文号与清缴节点（如国环规气候〔2025〕2号、〔2026〕1号）；
  - 激励政策（如《关于开展零碳工厂建设工作的指导意见》工信部联节〔2026〕13号）对应的培育行业与时间表；
  - 企业所在地区（贵州/重庆/广东等）碳达峰方案作为地方目标锚点。
- 记录文号、发布日期、时效状态、数据状态；未命中不得编造，改用 references 并标注"待核"。

### 4. 梳理减排措施与潜力并测算
- 分类减排杠杆：能效提升、可再生能源、电气化、工艺改进、绿色采购、CCUS。
- 用 `scripts/roadmap_calc.py` 测算各措施的年减排量、投资与时间；传入 `--industry` 自动附加第 2–3 步查询到的行业规则与政策时间表标注。

### 5. 规划时间表与残余抵消
- 排定分阶段实施计划（近/中/长期），里程碑对齐第 3 步政策时间表（碳市场扩围节点、零碳工厂培育批次、3060 目标）。
- 残余排放用碳汇/CCER 抵消（CCER 规则见政策表《温室气体自愿减排交易管理办法（试行）》生态环境部令第31号，衔接 `carbon-sink`/`carbon-policy`）。

### 6. 编制路线图并标注
- 输出：目标体系 → 措施清单（含减排量/成本/时序）→ 里程碑 → 治理与监测。
- 必做标注：**核算标准版本**（行业表）、**政策时间表依据**（文号+日期+数据状态，来自政策表/行业表）、**排放因子来源与数据状态**、估算项明确标注。
- 交付：路线图文档走 `word`/`lark-doc`，目标-措施矩阵走 `sheet`，路径可视化配合 `doubao-visualization`。

## 规范
- 减排量测算须有依据（能效、能源结构变化），不夸大效果；成本为估算并标注。
- 碳中和定义（抵消范围、口径）须明确，符合主流标准（如 PAS 2060、ISO 14068 方向）。
- 涉及对外承诺（SBTi 等）建议专业机构核验。

### 质量保证与数据规范
- **基线坚实原则**：以经核算的真实排放数据为基线，不凭空估算基准年排放，基准年选择需有代表性。
- **减排优先原则**：遵循"减排优先、抵消补充"逻辑，不得以碳信用抵消替代实质性减排措施。
- **测算有据原则**：每项减排措施的减排量、成本、实施周期均有技术文献、行业基准或对标案例支撑。
- **目标对齐原则**：若声明 SBTi / 净零等特定标准，目标年限、范围覆盖、抵消比例应基本符合对应标准要求；行业合规节点以数据层政策时间表为准。
- **动态修订原则**：路线图应规划定期更新机制（每 3-5 年或重大变化时），适应政策（数据层更新）、技术、市场变化。
- 完成路线图编制后，应使用 `references/quality-checklist.md` 逐项自检，通过后方可交付。

### 来源与引用规范
- 所有减排潜力数据、技术成本、行业基准均需标注来源（机构、报告名、年份）；政策节点引用数据层文号与日期。
- **已实现措施**（有历史数据）与**规划措施**（预测性）严格区分，预测值注明关键假设与不确定性。
- 引用优先级：国际标准（ISO / SBTi / GHG Protocol）> 国家政策文件（数据层政策表）> IEA / IPCC 等权威机构报告 > 行业协会数据 > 咨询公司报告 > 学术文献。
- 行业基准数据应注明地区与年份，中国企业优先采用国内数据与政策要求。
- 标准与数据来源的详细清单参见 `references/standards-sources.md`（历史参考，以数据层为准）。

### 边界与免责
- 本 Skill 提供碳中和路径规划的方法论与框架支持，不构成对目标可达性的绝对保证。
- 本 Skill 不构成法律、财务或投资建议；企业实际碳目标声明、对外披露或 SBTi 提交前，建议由专业机构核验。
- 减排潜力与成本测算基于当前技术水平与市场条件，未来技术突破、政策变化、价格波动可能导致结果偏差。
- 本 Skill 不替代正式的第三方核查或认证；若用于正式披露或品牌宣传，应进行独立验证。
- 路线图是动态文件，企业应根据实际进展与外部变化定期修订，不能一次性规划到底。
