# MRV 体系搭建与核查准备质量检查清单

## 一、监测计划
| 检查项 | 通过标准 |
|--------|----------|
| 排放源识别完整 | 纳入适用 MRV 规则要求的全部排放设施与排放源，无遗漏 |
| 核算方法明确 | 每个排放源的核算方法（实测法 / 物料衡算法 / 缺省因子法）明确，选择符合 MRV 指南优先级 |
| 监测参数齐全 | 所有活动数据与排放因子对应的监测参数、监测点、监测频率全部列出 |
| 计量器具匹配 | 计量器具精度、量程、安装位置满足 MRV 指南对 CEMS / 流量计 / 衡器的要求 |
| 监测责任到人 | 每项数据的采集、录入、审核责任人明确，岗位职责清晰 |

## 二、数据质量控制
| 检查项 | 通过标准 |
|--------|----------|
| 数据来源可追溯 | 每条活动数据有原始凭证（计量记录、采购发票、化验报告、DCS 日志等）对应 |
| 计量器具校准 | 强检器具在检定有效期内，校准 / 检定证书齐全，精度等级符合要求 |
| 缺失数据处理规范 | 数据缺失时有明确的替补方法（插补 / 类比 / 缺省值），并记录原因与影响 |
| 异常数据识别机制 | 建立异常值判定标准（阈值 / 趋势偏离），异常数据有调查记录与处理说明 |
| 数据交叉验证 | 关键数据（如燃料消耗量 vs 产量 / 产汽量）有交叉核对机制，偏差范围可控 |

## 三、报告编制
| 检查项 | 通过标准 |
|--------|----------|
| 报告结构符合模板 | 排放报告章节、表格、格式符合主管部门发布的模板要求 |
| 数据口径一致 | 报告数据与监测记录、财务数据、生产统计数据口径一致，差异有说明 |
| 单位与换算正确 | 热值、标煤、碳含量、氧化率等换算公式正确，单位匹配无错配 |
| 佐证材料齐备 | 支撑报告数据的原始凭证、计算过程、辅助说明材料可随时调取 |
| 版本与签署合规 | 报告版本号、编制 / 审核 / 批准签字、公章符合要求 |

## 四、核查准备
| 检查项 | 通过标准 |
|--------|----------|
| 资料清单完整 | 按核查机构要求准备全部资料（监测计划、原始记录、台账、报告、制度文件等） |
| 人员准备到位 | 熟悉各排放源数据来源与计算过程的对接人明确，能回答核查问题 |
| 现场核查条件 | 现场核查路线、计量器具位置、文件存放等提前安排，不影响正常生产 |
| 不符合项整改机制 | 对核查中发现的问题有快速响应与整改流程，整改证据可闭环 |

## 五、制度与持续改进
| 检查项 | 通过标准 |
|--------|----------|
| 内部管理制度健全 | 企业碳排放管理制度 / 办法正式发布，职责、流程、考核机制明确 |
| 数据留存合规 | 电子与纸质数据留存期限符合 MRV 规则要求（一般不少于 5 年） |
| 年度复盘与改进 | 每年核查后进行复盘，识别数据管理薄弱环节，制定下一年度改进计划 |
| 人员能力保障 | 碳数据管理与报告人员定期培训，了解最新政策与方法学更新 |
