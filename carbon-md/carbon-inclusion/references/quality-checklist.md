# 碳普惠体系搭建与碳积分运营质量检查清单

> 历史参考，以 _data 数据层为准（2026-10-09）：清单涉及的顶层政策依据（部令第31号）与地方政策适用性（贵州/重庆/广东）以 `_data` 政策元数据表查询结果为准；本清单为交付前自检框架。

## 一、机制设计
| 检查项 | 通过标准 |
|--------|----------|
| 目标定位清晰 | 明确碳普惠体系的核心目标（行为引导 / 公众参与 / 品牌传播 / 减排交易），不偏离 |
| 参与对象明确 | 个人 / 家庭 / 小微企业 / 社区等参与主体界定清晰，准入规则明确 |
| 场景选择合理 | 绿色出行、节能减碳、绿色消费、循环利用等场景选择可量化、可落地、数据可得 |
| 减排量核算有据 | 每个场景的减排量计算方法与参数有权威来源或科学依据，方法透明可解释 |
| 积分换算规则公平 | 减排量 → 积分的换算逻辑合理，不同场景间积分价值相对均衡，避免严重失衡 |

## 二、减排量核算
| 检查项 | 通过标准 |
|--------|----------|
| 基线设定保守 | 基线情景选择取高值（保守估算减排量），不夸大减排效果 |
| 活动数据可获取 | 用户行为数据可通过 APP / 设备 / 支付记录等方式获取，不依赖不可验证的自报 |
| 排放因子权威 | 减排量计算使用的排放因子（电网因子、交通因子、产品因子等）来自官方或权威机构 |
| 方法学透明度高 | 每个场景的核算公式、参数来源、假设条件公开说明，接受公众监督 |
| 避免重复计算 | 用户同一行为不重复计入多个场景或多个平台，碳减排量不重复交易 / 使用 |

## 三、积分体系与运营
| 检查项 | 通过标准 |
|--------|----------|
| 积分获取规则清晰 | 用户可清晰理解哪些行为能获得多少积分，规则公开透明 |
| 积分消费 / 兑换场景丰富 | 积分可兑换的权益（商品 / 服务 / 优惠 / 荣誉）有吸引力，兑换比例合理 |
| 积分有效期合理 | 积分有效期设置兼顾用户参与度与体系可持续性，过期规则明确告知 |
| 用户体验流畅 | 注册、授权、行为记录、积分查看、兑换全流程用户体验良好，门槛低 |
| 防作弊机制健全 | 刷分、虚假行为、账号滥用等风险有识别与防控机制 |

## 四、数据与隐私合规
| 检查项 | 通过标准 |
|--------|----------|
| 个人信息保护 | 遵循《个人信息保护法》，最小必要原则收集用户数据，有明确的隐私政策 |
| 数据安全保障 | 用户数据加密存储、传输，防止泄露与滥用 |
| 用户授权充分 | 数据采集与使用获得用户明示同意，用户有撤回授权与注销账号的权利 |
| 数据使用边界清晰 | 用户数据仅用于碳普惠体系运营，不超范围使用或共享给第三方（法律要求除外） |

## 五、合规与可持续运营
| 检查项 | 通过标准 |
|--------|----------|
| 碳积分属性界定清晰 | 明确碳积分是平台权益积分而非法定碳资产，不与金融产品挂钩，不开展非法金融活动 |
| 减排量交易合规 | 若涉及碳普惠减排量交易，须在合规交易场所进行，符合自愿减排规则 |
| 第三方核查机制 | 减排量核算方法与数据定期接受第三方核查或审计，保证公信力 |
| 资金 / 运营可持续 | 平台运营资金来源、激励成本、商业模式可持续，不依赖短期补贴 |
| 政府监管对接 | 对接地方碳普惠主管部门（如有），符合地方碳普惠管理办法要求 |
