# Carbon Inclusion  碳普惠体系搭建与碳积分运营

## Overview

支持搭建碳普惠体系：将个人/小微企业的低碳行为量化、累积碳积分并提供激励，引导社会低碳参与。核心产出：机制设计 → 减排量核算 → 积分规则 → 运营与对接。碳普惠减排量核算衔接 `carbon-accounting`，可对接自愿减排与平台运营。

本 Skill 为**数据驱动模式**：政策依据与地区适用性从 `data/` 政策元数据表查询；减排因子优先从因子库查询，数据层无对应行为因子时回退 `references/inclusion-guide.md` 历史参数并显式标注。

## 数据层（机制设计前必读）

政策依据与地区适用性从 `data/` 数据层政策元数据表查询；节电类减排因子从排放因子库查询。其他行为因子（绿色出行、垃圾分类等）数据层暂无对应记录时回退 `references/inclusion-guide.md` 并标注。

| 内容 | 数据文件 | 统一查询命令 |
|---|---|---|
| 政策元数据表（碳普惠政策、CCER、地方试点） | `data/policy/policy_metadata.json` | `python data/scripts/query_data.py search-policy <关键词>` |
| 电网排放因子库（节电类场景） | `data/factors/grid_electricity_factors.json` | `python data/scripts/query_data.py get-grid-factor --year <年份> --region <区域>` |
| 数据版本号 | — | `python data/scripts/query_data.py version` |

> 运行路径：在 `carbon-md/` 根目录下执行上述命令。

数据状态约定：数据层每条记录含 `confidence` 或 `status` 字段，引用时必须透传，不得把估算/占位当已查证输出。碳普惠专门方法学与地方管理办法数据层暂无专门记录时，回退 references 并标注。

## Workflow

### 1. 明确运营主体、目标、参与场景与适用地区
- 确认运营主体（政府/园区/品牌企业）、目标与参与场景（绿色出行、节能、绿色消费、循环利用等）。
- 确定适用地区（影响地方政策与因子口径），如贵州/重庆/广东等。

### 2. 从政策表查询碳普惠相关政策与地区差异
- 顶层依据：执行 `python data/scripts/query_data.py search-policy 自愿减排` 和 `python data/scripts/query_data.py search-policy CCER`，获取《温室气体自愿减排交易管理办法》作为碳普惠减排量进入自愿减排市场的制度衔接依据，透传真号、日期与数据状态。
- 地方政策差异：按适用地区执行 `python data/scripts/query_data.py search-policy 适用地区="贵州省")` / `("重庆市")` / `("广东省")` 等，查询该省碳达峰/双控等顶层政策作为本地机制的政策背景。
- **碳普惠专门方法学与地方管理办法（如广东碳普惠、北京出行方法学）数据层暂无专门记录**，回退 `references/inclusion-guide.md` 与 `references/standards-sources.md`，并标注"地方碳普惠规则为 legacy 参考，以当地主管部门最新备案方法学为准"，不跨地区套用。

### 3. 从因子库查询减排因子（query_factor，查不到则 legacy 回退）
- **节电类场景**（节能行为：节省电量 × 电力碳足迹因子）：执行 `python data/scripts/query_data.py <对应因子命令> 能源类型="电力碳足迹", 年份=...)`，取得全国电力平均碳足迹因子（如 2023 年 0.6205、2024 年 0.5777 kgCO2e/kWh，已查证），并透传来源与数据状态。
- **其他行为因子**（绿色出行、公交/地铁/骑行、垃圾分类等单位减排因子）：数据层因子库暂无对应记录，回退 `references/inclusion-guide.md` 历史参考值，标注"legacy 回退；应采用项目所在城市/地方已备案方法学的因子"。

### 4. 执行减排量与积分测算（scripts/inclusion_calc.py）
- 用 `scripts/inclusion_calc.py` 测算单场景减排量与积分换算。
- 行内显式 `--factor` 直接使用（兼容原行为）；节电场景可用 `--scenario electricity --saving-kwh <度> --year <年>` 自动从因子库查询电力碳足迹因子填充，数据层查不到时回退 legacy 常数并标注。

### 5. 输出标注（必做）
- 在输出/运营方案中标注：**政策依据文号与日期**（部令第31号及适用地区政策，来自政策表与数据状态）、**地区适用性**（明确适用地方规则，不跨地区套用）、**减排因子来源与年份**（数据层/legacy 回退）、**积分系数为运营自定义**说明。

## 规范
- 减排量核算方法须合理、可量化，避免虚高；注明方法与来源。
- 涉及个人信息收集须合规（隐私、数据安全）。
- 碳积分不等同于法定碳资产，价值化须符合规则。

### 质量保证与数据规范
- **减排保守原则**：碳普惠减排量核算采用保守假设（基线取高值、减排量取低值），避免夸大减排效果，维护公信力。
- **方法透明原则**：每个行为场景的核算方法、参数、假设均公开说明，接受公众与第三方监督。
- **数据可证原则**：用户行为数据应可通过设备、支付、出行记录等方式验证，不依赖用户自报的不可信数据。
- **隐私优先原则**：用户个人信息采集遵循最小必要原则，严格遵守《个人信息保护法》等法律法规。
- **积分定性原则**：明确碳积分是平台权益积分而非法定碳资产，不与金融产品挂钩，不开展非法集资、代币发行等活动。
- 完成碳普惠机制设计或运营方案后，应使用 `references/quality-checklist.md` 逐项自检，通过后方可落地。

### 来源与引用规范
- 减排量核算方法、排放因子、基线数据均需标注来源（发布机构、文件名称、年份）；政策文号优先透传自 `_data` 政策元数据表记录。
- **实测 / 监测数据**与**模型估算 / 默认值**严格区分，估算值注明方法与假设条件。
- 引用优先级：地方碳普惠管理办法与官方方法学 > 生态环境部 / 主管部门发布的因子与指南 > IPCC 指南 > 权威研究机构报告 > 学术文献。
- 不同地区的碳普惠制度差异较大，应明确适用的地方规则（用 `search-policy(适用地区=...)` 核对），不跨地区套用方法学。
- 标准与数据来源的详细清单参见 `references/standards-sources.md`。

### 边界与免责
- 本 Skill 提供碳普惠体系设计与碳积分运营的方法论指导，不保证体系一定获得政府备案或商业成功。
- 本 Skill 不构成法律、金融或合规建议；碳普惠运营涉及个人信息保护、消费者权益、积分合规等法律问题，建议咨询专业律师。
- 本 Skill 不对碳减排量的真实性、准确性做保证，减排量数据质量取决于行为数据采集与核算方法的可靠性。
- 碳积分不得变相发行代币、不得开展非法金融活动，运营方应自行评估合规风险。
- 碳普惠政策在各地发展不均衡，且政策可能调整，具体落地前应与当地主管部门沟通确认。
