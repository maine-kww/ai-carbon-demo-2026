# CCER Development  CCER 自愿减排项目开发

## Overview

按数据层查询到的《温室气体自愿减排交易管理办法（试行）》（部令第31号）与生态环境部备案方法学，将符合条件的减排项目开发为国家核证自愿减排量（CCER），覆盖从方法学匹配、项目设计文件（PDD）、减排量核算到备案与核证全流程。核心产出：项目适用性判断 → PDD → 减排量测算 → 备案核证路径。

本 Skill 为**数据驱动模式**：管理办法与制度依据（文号、发布日期、时效状态）从 `data/` 政策元数据表查询，不在本文件写死具体规章编号；数据层暂无方法学参数表，方法学清单以生态环境部最新公告为准（`ccer_calc.py` 的计入期年数为历史参考值，须按适用方法学核对）。

## 数据层（开发前必读）

CCER 管理办法与制度依据、项目所属行业规则均从 `data/` 数据层动态查询，**不在本 Skill 中写死具体规章编号**。方法学清单以生态环境部最新公告为准。

| 内容 | 数据文件 | 统一查询命令 |
|---|---|---|
| 政策元数据表（CCER 管理办法、抵消规则） | `data/policy/policy_metadata.json` | `python data/scripts/query_data.py search-policy CCER` |
| 行业规则表（项目所属行业纳入与抵消衔接） | `data/industry/industry_rules.json` | `python data/scripts/query_data.py get-industry <行业名>` |
| 列出全部政策 | `data/policy/policy_metadata.json` | `python data/scripts/query_data.py list-policies` |
| 数据版本号 | — | `python data/scripts/query_data.py version` |

> 运行路径：在 `carbon-md/` 根目录下执行上述命令。

数据状态约定：数据层每条记录含 `confidence` 或 `status` 字段，输出依据时必须透传文号、日期与数据状态。
## Workflow

### 1. 项目适用性与方法学匹配
- 确认项目类型（可再生能源、林业碳汇、甲烷利用、节能等）与减排机制。
- 匹配适用方法学：读取 `references/methodology-guide.md` 对照条件、计入期与额外性要求；方法学清单以生态环境部最新备案公告为准。
- 判断是否满足"额外性"：项目减排量须超过基准线情景且有政策/技术/资金障碍。

### 2. 从数据层查询制度依据（search-policy）
- 执行 `python data/scripts/query_data.py search-policy 自愿减排` 和 `python data/scripts/query_data.py search-policy CCER`，获取《温室气体自愿减排交易管理办法》等制度依据的**文号、发布机关、发布日期、时效状态、原文链接、数据状态**，作为本项目开发的制度依据（不再凭记忆写死）。
- 抵消用途与比例上限：执行 `python data/scripts/query_data.py search-policy "CCER" / 政策类型="配额方案")` 核对控排企业抵消规则，记录依据文号。
- 数据层未覆盖的方法学细则：标注"数据层暂无记录，以生态环境部最新公告为准"。

### 3. 编制项目设计文件（PDD）
- 按模板组织：项目概述、基准线设定、额外性论证、监测计划、减排量预估、环境影响。
- 引用 `references/pdd-guide.md` 核对必备要素与常见退回原因。

### 4. 减排量测算（scripts/ccer_calc.py）
- 使用 `scripts/ccer_calc.py` 按方法学公式计算计入期内减排量：减排量 = 基准线排放 − 项目排放 − 泄漏。
- 脚本自动查询数据层管理办法依据并标注文号/日期/数据状态；计入期年数（--years）依适用方法学核对（默认 10 为历史参考值）。
- 引用 `carbon-accounting` 的排放因子做交叉核对。

### 5. 审定与备案
- 委托具备资质的审定与核证机构（DOE）审定 PDD。
- 提交生态环境部及指定机构备案、登记。

### 6. 监测与核证、交易（含标注）
- 项目运行后按监测计划收集数据，委托核证机构核证减排量。
- 核证自愿减排量可进入交易市场或用于控排企业抵消（比例上限以数据层配额方案记录为准，并附文号/日期/数据状态）。

## 规范
- 方法学与规则随时更新，以生态环境部最新公告为准；减排量须可核查、不重复计算。
- 涉及真实项目备案/融资，建议由专业机构与法律顾问介入。
- 不编造项目数据；PDD 关键数据须可追溯。

### 质量保证与数据规范
- **方法学唯一原则**：一个项目仅适用一种方法学，不混用、不自创方法，严格遵循方法学规定的公式、参数与监测要求。
- **额外性从严原则**：额外性论证采用保守假设，基线情景选择取高值、项目排放取高值，使减排量估算不被高估。
- **数据可追溯原则**：所有活动数据、排放因子、技术参数均有原始凭证（合同、发票、监测记录、卫星影像等）支撑。
- **不重复计算原则**：项目未在其他碳机制（VCS、GS、CDM 等）重复注册，同一减排量不重复计入。
- **审定核证独立原则**：审定与核证机构必须在主管部门公布的资质名录内，且与项目方无利益冲突。
- 完成 PDD 或项目评估后，应使用 `references/quality-checklist.md` 逐项自检，通过后方可提交或交付。

### 来源与引用规范
- 方法学、规则文件均引用生态环境部等主管部门**最新有效版本**，标注文号与发布日期。
- **事实**（有官方来源的数据/规则）与**预测/估算**（如未来发电量、碳汇增量预测）严格区分，预测值须注明假设条件。
- 引用优先级：生态环境部 / 国家发改委发布的方法学与办法 > 国家温室气体排放因子数据库 > IPCC 指南 > 行业协会指南 > 学术文献。
- 涉及省级电网因子、林业参数、作物系数等地域敏感数据，必须使用项目所在地对应数据。
- 标准与数据来源的详细清单参见 `references/standards-sources.md`。

### 边界与免责
- 本 Skill 仅提供 CCER 项目开发的方法指导与测算参考，不替代具备资质的审定核证机构工作。
- 本 Skill 不构成法律、财务或投资建议；项目实际备案能否通过、减排量能否签发，以主管部门审核为准。
- 本 Skill 不负责项目数据真实性与合法性核实，项目方对提供数据的真实性、完整性负责。
- CCER 政策与方法学处于动态更新中，相关规则以主管部门最新公告为准，使用时应核实时效性。
- 涉及土地权属、原住民权益、环境社会影响等复杂法律问题，建议咨询专业律师与合规机构。
