# PDD 必备要素与审定要点

> 用于编制 CCER 项目设计文件（PDD）与自查。

## 必备章节
1. **项目概述** — 项目名称、业主、类型、地点、技术路线。
2. **基准线情景** — 无本项目时的排放情景设定与依据。
3. **额外性论证** — 障碍/投资分析，证明项目非自然实施。
4. **项目边界与排放源** — 明确纳入的排放源与排除项。
5. **减排量计算** — 公式、参数、排放因子、预估计入期减排量。
6. **监测计划** — 监测指标、方法、频率、数据管理与质量控制。
7. **环境影响与可持续性** — 环境、社会、经济效益说明。

## 审定关注点
- 方法学是否适用、边界是否完整。
- 基准线与额外性论证是否充分、可验证。
- 减排量公式与参数取值是否正确，有无重复计算。
- 监测计划是否可行、数据是否可核查。

## 自查清单
- [ ] 项目类型在已备案方法学范围内
- [ ] 基准线情景合理且有依据
- [ ] 额外性论证有量化支撑
- [ ] 减排量按方法学公式计算、参数有来源
- [ ] 监测计划可执行、数据口径一致
- [ ] 与 CCER 登记要求匹配
