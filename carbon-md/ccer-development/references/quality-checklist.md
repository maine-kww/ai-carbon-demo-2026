# CCER 自愿减排项目开发质量检查清单

## 一、项目边界与方法学选择
| 检查项 | 通过标准 |
|--------|----------|
| 方法学适用性匹配 | 所选 CCER 方法学与项目类型（造林、可再生能源、甲烷利用等）完全匹配，不超范围使用 |
| 项目边界清晰 | 地理边界、设施边界、温室气体种类边界明确，基线与项目情景边界一致 |
| 计入期选择合理 | 计入期长度、起止时间符合方法学规定，可再生能源类与造林类区分正确 |
| 额外性论证完整 | 额外性论证按方法学要求的步骤（投资分析、障碍分析、普遍性分析等）全部完成 |
| 项目活动唯一性 | 项目未在其他碳市场或机制下重复注册，无双重计算风险 |

## 二、基线与减排量计算
| 检查项 | 通过标准 |
|--------|----------|
| 基线情景确定有据 | 基线情景选择有数据支撑，符合方法学规定的默认值或保守性原则 |
| 泄漏评估到位 | 按方法学要求评估项目活动导致的泄漏（转移排放），计入或排除有依据 |
| 减排量公式正确 | 使用方法学规定的公式：减排量 = 基线排放 - 项目排放 - 泄漏，无自创公式 |
| 监测参数完整 | 所有需要监测的参数（发电量、燃料消耗、土地面积、碳储量变化等）清单齐全 |
| 数据测量方法合规 | 监测方法、频率、精度符合方法学与 GB/T 32150/32151 等标准要求 |

## 三、文档与报告
| 检查项 | 通过标准 |
|--------|----------|
| PDD 文档完整 | 项目设计文件（PDD）包含方法学要求的全部章节，格式符合主管部门模板 |
| 项目描述详实 | 项目技术方案、参与方、资金来源、实施进度等信息真实可核实 |
| 利益相关方意见 | 已开展利益相关方咨询并形成记录，意见有回应 |
| 监测计划齐备 | 监测计划（MP）参数、方法、频率、责任方、数据管理流程全部明确 |
| 版本与变更可追溯 | 文档版本号、修订日期、变更说明清晰，关键变更有审定/核证机构确认 |

## 四、审定与备案
| 检查项 | 通过标准 |
|--------|----------|
| 审定机构资质 | 委托的审定机构在主管部门公布的名录内，且对应方法学在其认可范围内 |
| 公示与异议处理 | 项目在指定平台公示，公示期与异议处理程序符合规定 |
| 备案材料齐全 | 备案申请材料（PDD、审定报告、公示说明等）齐全，格式符合要求 |
| 监测报告与核证 | 计入期内监测报告按要求编制，并经核证机构核证通过 |

## 五、合规与风险
| 检查项 | 通过标准 |
|--------|----------|
| 土地权属清晰 | 林业、农业类项目土地权属证明完整，使用权期限覆盖计入期 |
| 环境社会影响评估 | 项目不存在重大环境负面影响、不涉及移民搬迁与原住民权益纠纷 |
| 方法学更新应对 | 关注方法学修订与政策变化，确保项目持续符合最新要求 |
| 不重复计算承诺 | 项目未同时申请国际自愿减排（VCS/GS）或其他机制，避免双重收益 |
