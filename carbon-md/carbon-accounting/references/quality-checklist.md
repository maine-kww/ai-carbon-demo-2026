# 碳排放核算质量检查清单

> 核算完成后逐项检查，确保数据质量和合规性。每项打勾后再输出结果。

## 一、边界完整性

- [ ] **核算主体明确**：企业/设施/项目/产品，边界清晰
- [ ] **组织边界方法确定**：运营控制法 / 股权法 / 财务控制法
- [ ] **报告期明确**：具体起止日期
- [ ] **范围 1 排放源完整**：
  - [ ] 固定燃烧（锅炉、窑炉等）
  - [ ] 移动燃烧（车辆、叉车等）
  - [ ] 工艺排放（生产过程化学反应）
  - [ ] 逸散排放（制冷剂泄漏、CH4 逸散等）
- [ ] **范围 2 排放源完整**：
  - [ ] 外购电力
  - [ ] 外购蒸汽/热水/热力
  - [ ] 外购冷能（如适用）
- [ ] **范围 3 排放源（如需）**：按重要性原则梳理至少前 5 大类

## 二、数据质量

- [ ] **活动数据有来源**：每条数据标注来源（计量表/结算单/发票/估算）
- [ ] **数据单位与因子单位匹配**：kWh vs MWh、万Nm³ vs Nm³ 等已统一
- [ ] **排放因子有出处**：每个因子标注发布机构与年份
- [ ] **因子时效性正确**：使用报告期对应的年度最新因子
- [ ] **GWP 版本一致**：全文统一使用 AR5 或 AR6，已在报告中注明
- [ ] **估算项已标注**：所有估算数据显式标记（估算），并说明估算方法
- [ ] **关键排放源数据质量 ≥ B 级**：占总排放 80% 以上的排放源活动数据质量不低于 B 级

## 三、计算准确性

- [ ] **公式正确**：排放量 = 活动数据 × 排放因子 × GWP − 回收量
- [ ] **单位换算正确**：已检查所有非标准单位的换算系数
- [ ] **回收/扣除量有依据**：所有扣除项有实测或正式文件支撑
- [ ] **汇总正确**：分项之和 = 分范围汇总 = 总排放量
- [ ] **小数位一致**：所有结果保留相同小数位（建议 2 位）

## 四、报告规范

- [ ] **报告结构完整**：按 report-guide.md 的 7 个章节组织
- [ ] **假设与不确定性说明**：关键假设和不确定性已说明
- [ ] **与上期对比（如有）**：口径变更已注明并重述
- [ ] **来源标注完整**：每个因子和关键数据都有引用
- [ ] **免责声明**：不构成核查结论的声明已包含

## 五、常见错误检查

- [ ] kWh 与 MWh 混淆（差 1000 倍！）
- [ ] 天然气 万Nm³ 与 Nm³ 混淆（差 10000 倍！）
- [ ] 排放因子单位写反（tCO2/t vs t/tCO2）
- [ ] 范围 1 / 范围 2 排放源归类错误
- [ ] 重复计算（同一排放源既算燃烧又算工艺）
- [ ] GWP 未乘到非 CO2 气体上
- [ ] 回收量超过排放量（出现负数，应检查是否合理）
- [ ] 电网排放因子用了旧年份的值
- [ ] 组织边界方法与运营边界混淆
- [ ] 忘了标注估算数据，把估算当成实测

> 💡 **建议流程**：先完成核算 → 对照本清单逐项检查 → 发现问题修正 → 再检查一遍 → 输出报告
