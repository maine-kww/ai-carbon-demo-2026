# 核算标准与排放因子来源索引

> 核对排放因子出处、方法学依据时查阅。所有因子使用时必须标注来源机构和发布年份。

## 一、国际标准与方法学

### GHG Protocol
- **全称**：温室气体核算体系（Greenhouse Gas Protocol）
- **发布方**：世界资源研究所（WRI）+ 世界可持续发展工商理事会（WBCSD）
- **核心文件**：
  - 《企业核算与报告标准》（Corporate Standard）
  - 《企业价值链（范围 3）核算与报告标准》
  - 《产品核算与报告标准》（Product Standard）
  - 《项目核算协议》（Project Protocol）
- **适用范围**：全球最广泛采用的企业温室气体核算框架
- **官网**：ghgprotocol.org

### ISO 14064 系列
- **ISO 14064-1**：组织层面温室气体排放的量化和报告
- **ISO 14064-2**：项目层面温室气体减排的量化、监测和报告
- **ISO 14064-3**：温室气体声明的审定和核查
- **发布方**：国际标准化组织（ISO）
- **适用范围**：国际通用，常与 GHG Protocol 配合使用

### ISO 14067
- **全称**：温室气体 — 产品碳足迹 — 量化要求与指南
- **发布方**：ISO
- **适用范围**：产品层面碳足迹核算

### IPCC 指南
- **全称**：政府间气候变化专门委员会国家温室气体清单指南
- **版本**：2006 IPCC Guidelines / 2019 Refinement
- **GWP 值来源**：AR5（第五次评估报告）/ AR6（第六次评估报告）
- **用途**：提供缺省排放因子和 GWP 值的权威来源

## 二、中国官方标准与指南

### 行业核算报告指南（生态环境部）
- **全称**：《XX 行业温室气体排放核算方法与报告指南》
- **发布方**：生态环境部（原国家发改委气候司）
- **已发布行业**：
  - 发电设施（2022 修订版）
  - 钢铁生产企业
  - 水泥生产企业
  - 电解铝生产企业
  - 化工生产企业
  - 平板玻璃生产企业
  - 造纸生产企业
  - 民航企业
  - 其他...
- **用途**：全国碳市场配额分配和企业排放核算的官方依据
- **获取渠道**：生态环境部官网 / 全国碳排放权注册登记结算有限责任公司

### 国家标准（GB/T 系列）
- **GB/T 32150-2015**：工业企业温室气体排放核算和报告通则
- **GB/T 32151.1~.10**：各行业温室气体排放核算与报告要求
- **GB/T 24064-2009**：环境管理 环境信息沟通指南
- **GB/T 33760-2017**：基于项目的温室气体减排量评估技术规范

### 全国电网排放因子
- **发布方**：生态环境部 / 中电联 / 国家应对气候变化战略研究中心
- **更新频率**：每年更新，对应上一年度
- **近年参考值**：
  - 2022 年度：约 0.5703 tCO2/MWh（全国平均）
  - 2021 年度：约 0.5719 tCO2/MWh
  - 2019 年度：约 0.5810 tCO2/MWh
- **注意**：核算必须使用报告期对应年度的最新因子，不得使用过期值
- **获取渠道**：生态环境部公告 / 全国碳市场官网

### 中国温室气体清单
- **发布方**：生态环境部
- **内容**：国家层面温室气体排放清单，提供分行业、分气体数据
- **用途**：省级/国家级核算参考

## 三、排放因子库

### IPCC 缺省排放因子
- **来源**：IPCC 2006 指南 / 2019 Refinement Volume 2 Energy
- **内容**：各类燃料的缺省排放因子、GWP 值
- **适用场景**：无本国/本地区因子时的替代

### 中国能源统计年鉴
- **发布方**：国家统计局
- **内容**：能源消费量、能源结构、能源效率等基础数据
- **用途**：活动数据来源参考、宏观排放量核算

### 省级温室气体清单
- **发布方**：各省市生态环境厅/局
- **内容**：省级排放因子、电网因子、能源结构
- **用途**：地方项目核算优先采用省级因子

## 四、使用优先级（从高到低）

1. **实测排放因子**（企业自测、经第三方核验）
2. **行业/省级主管部门发布值**（针对本行业、本地区）
3. **生态环境部核算指南附件因子**（全国行业基准）
4. **国家温室气体清单因子**（宏观统计）
5. **IPCC 缺省因子**（最后选项，必须标注为缺省值）

> ⚠️ **重要原则**：因子必须与活动数据的时间、地域、行业匹配。不得直接跨行业、跨地区、跨年代借用。

## 五、引用格式规范

在报告中引用时使用以下格式：

```
[生态环境部, 2024] 全国电网平均排放因子 0.5703 tCO2/MWh（2022 年度）
[IPCC AR6, 2021] 甲烷 GWP-100 = 28
[中国钢铁工业协会, 2023] 粗钢单位产品排放因子 1.8 tCO2/t
```

引用标准时使用完整名称：

```
《中国发电企业温室气体排放核算方法与报告指南（试行）》（发改办气候〔2013〕2526 号，2022 修订版）
《工业企业温室气体排放核算和报告通则》（GB/T 32150-2015）
```
