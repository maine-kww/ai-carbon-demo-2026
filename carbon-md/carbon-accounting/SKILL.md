# Carbon Accounting 碳排放核算与报告

## Overview

依据规范方法学，将活动数据（能源消耗、生产量、外购电力等）与对应排放因子相乘，核算温室气体排放量，并输出结构化的碳排放报告。核心公式：**排放量 = 活动数据 × 排放因子 × GWP −（1 − 回收/扣除量）**。

本 Skill 为**数据驱动模式**：行业规则、核算标准、排放因子、政策依据一律从 `_data/` 数据层动态查询，不在本文件写死任何行业参数。

## 数据层（核算前必读）

| 内容 | 路径 / 接口 |
|---|---|
| 行业规则表 | `_data/industry_rules.json`（query.py → `query_industry`） |
| 排放因子库 | `_data/emission_factors.json`（query.py → `query_factor`） |
| 国际排放因子库 | `_data/ghg_factors\ghg_factors_index.json`（query.py → `query_ghg`，967 条，ghg-calculator/MIT） |
| 政策元数据表 | `_data/policy_meta.json`（query.py → `query_policy`） |
| 统一查询接口 | `_data/query.py`（CLI：`python query.py industry steel` 等，须在 `_data/` 目录下运行或带全路径） |

数据状态约定：数据层每条记录含 `数据状态` ∈ {已查证, 估算, 占位-待核实}，引用时必须透传，不得把估算/占位当已查证输出。

两套排放因子口径（不可混用）：
- `query_factor`（国内官方）：生态环境部/GB/T 口径，电力为 **CO2 因子**（如 0.5366 tCO2/MWh = 2022 全国平均）。核算中国境内、碳市场、产品碳足迹标识用此套。
- `query_ghg`（国际 ghg-calculator）：EPA/DEFRA/USEEIO/Ember/EXIOBASE，电力等为 **CO2e 因子**（含 CH4/N2O，AR5 GWP，如 Ember 中国 0.979 kgCO2e/kWh）。核算海外工厂/美国/欧盟/出口对标时用此套，与官方 CO2 值不可直接比较。

## Workflow

### 1. 确定核算边界与范围
- 询问或确定核算主体（企业/设施/项目/产品）、报告期、组织边界（运营控制 / 股权 / 财务控制法）与运营边界（范围 1/2/3）。
- 确认遵循的框架：GHG Protocol、ISO 14064-1、中国核算报告指南（发电、钢铁、水泥等行业）。

### 2. 确认行业、年度与地区（数据驱动起点）
- 确定核算主体所在行业（发电/钢铁/水泥/铝冶炼/石化/化工/造纸/航空/其他）与报告期年份、所在地区。
- 若行业不在 `industry_rules.json`：提示"该行业规则未建立/未纳入碳市场"，采用估算口径并在输出中标注。

### 3. 从行业规则表查询行业规则（query_industry）
- 调用 `query.py` 的 `query_industry(行业名称/行业代码)`，获取该行业：核算标准（GB/T 编号及版本）、排放因子来源、配额分配方法（强度法/总量法）、是否覆盖间接排放、核查机构要求。
- 从政策元数据表 `query_policy(适用行业=...)` 查询适用的核算指南、配额方案等，记录政策依据文号与日期。

### 4. 从排放因子库查询因子（query_factor）
- 按 行业 / 年份 / 能源类型 / 地区 调用 `query_factor()`；多条命中时优先"已查证"记录。
- 数据层查不到时，回退 `references/emission-factors.md` 历史参考值并在输出标注"legacy 回退"。

### 5. 执行计算（scripts/calc_emissions.py）
- 使用 `scripts/calc_emissions.py` 自动核算，输入结构化活动数据（CSV/JSON）。
- 行内显式给出排放因子 → 直接使用（兼容原行为）；未给出时用 `--industry / --year / --region` 自动从数据层查询填充（脚本内部通过 `_data/query.py` 查因子库）。
- 单位统一为 tCO₂e；非 CO₂ 温室气体（CH₄、N₂O 等）按 GWP 折算。

### 6. 输出标注（必做）
- 在输出中标注：**核算标准版本**（来自行业规则表）、**因子来源**（机构 + 年份 + 版本 + 数据状态）、**政策依据的文号和日期**（来自政策元数据表）、数据状态（已查证/估算/占位-待核实）。

## Data Input Format (for calc_emissions.py)

支持 CSV 或 JSON，字段约定见 `references/data-schema.md`。数据驱动模式示例（emission_factor 留空或填 `auto`）：

```csv
scope,facility,fuel_type,activity_data,unit,emission_factor,ef_unit,recovery
1,boiler-1,coal,100.5,t,,,0
2,plant,electricity,120000,kWh,auto,,0
```

执行：`python scripts/calc_emissions.py input.csv --industry steel --year 2024 --region 全国`

## 质量保证与数据规范

### 数据质量控制
- **来源追溯**：每个排放因子和活动数据必须标注来源（机构/文号/发布年份），数据层记录透传其 `来源/版本/数据状态`。无来源 = 估算项，须显式标记。
- **单位一致性**：活动数据单位与排放因子单位必须匹配。kWh/MWh、万Nm³/Nm³、t/kg 等常见单位错误须在计算前统一。
- **因子时效性**：电网排放因子、行业基准值等随年份更新，核算时必须使用报告期对应年度的最新发布值（以 `emission_factors.json` 中"已查证"记录为准）。
- **GWP 版本**：使用 IPCC AR5 或 AR6 必须在报告中明确注明，不得混用。中国官方核算指南默认采用 AR5。

### 不确定性管理
- 活动数据质量分级：A 级（实测/计量表）、B 级（结算单/票据）、C 级（估算/经验值）。
- C 级数据占比超过 10% 时，须在报告中说明对结论的影响。
- 关键排放源（占总排放 80% 以上）的活动数据必须达到 B 级以上。

### 核查与边界
- **边界完整性检查**：范围 1 须覆盖所有燃料燃烧 + 工艺排放 + 逸散排放（制冷剂等）；范围 2 须含外购电力 + 外购热力；范围 3 须按重要性原则梳理。
- **常见错误清单**：见 `references/quality-checklist.md`，核算完成后须逐项自检。
- **不得编造**：缺失数据必须标注为"待补充"或使用保守估算，不得凭空生成。

## 来源与引用规范

### 引用优先级
排放因子与方法学的采用按以下优先级从高到低选择，不得越级采用低优先级来源替代高优先级来源：
1. **国家标准与法规**：GB/T 系列国家标准、生态环境部发布的行业核算报告指南、全国碳市场官方规则
2. **行业指南与主管部门发布值**：行业核算报告指南附件中的排放因子、省级主管部门发布的地方排放因子、电网排放因子（生态环境部公告）
3. **IPCC 指南与缺省因子**：IPCC 2006 指南 / 2019 Refinement 中的缺省排放因子和 GWP 值（仅在无本国/本行业因子时使用）
4. **行业协会与研究机构数据**：行业协会发布的行业基准、研究机构报告（须标注来源，建议作为补充而非主依据）
5. **企业实测数据**：企业自测排放因子（须经第三方核验，否则仅作内部参考）

### 事实 vs 假设区分
- **事实数据**：实际计量的活动数据、官方发布的排放因子、已发布的标准方法 → 直接使用，标注来源
- **估算数据**：基于经验值、类比、推算得出的活动数据或因子 → 必须标注（估算），说明估算方法和依据
- **假设条件**：核算中采用的假设（如设备利用率、排放因子随时间的外推）→ 必须在报告中明确列出假设条件
- **不确定项**：来源存疑或有争议的数据 → 标注"待核"，说明不确定性和潜在影响范围

### 排放因子标注要求
- **格式规范**：排放因子引用统一使用 `[机构, 年份] 因子值 (单位) [数据状态]` 格式，如 `[生态环境部, 2022] 0.5366 tCO2/MWh [已查证]`
- **时效性标注**：电网排放因子、行业基准值等随年份更新的因子，必须注明对应年度
- **缺省因子标注**：使用 IPCC 缺省因子或 legacy 回退值时，必须明确标注为"缺省值/legacy 回退"，并说明为何未采用数据层更高优先级来源
- **GWP 版本标注**：使用 IPCC AR5 或 AR6 的 GWP 值必须在报告中明确注明，不得混用；中国官方核算指南默认采用 AR5
- **方法学引用**：标准全称 + 编号 + 版本/年份，如《中国温室气体排放核算方法与报告指南 发电设施》（2022 修订版）

完整的标准出处、因子库来源与引用格式见 `references/standards-sources.md`。

## 边界与免责

- 本 Skill 提供核算方法与工具支持，**不构成第三方核查结论**。正式报告发布前建议由具备资质的核查机构核验。
- 不处理需要资质盖章的法定报告（如企业年度排放报告），只提供技术核算与报告编制支持。
- 涉及具体行业的复杂工艺排放（如化工过程排放、电解铝阳极效应），须参考对应行业核算指南并补充专业工程判断。
- 范围 3（价值链排放）数据获取难度大，结果仅作参考，不得用于严格的履约目的。
