# 供应链碳管理（范围3）质量检查清单

## 一、边界与类别识别
| 检查项 | 通过标准 |
|--------|----------|
| 15 类全覆盖梳理 | 按 GHG Protocol 范围3 的 15 个类别逐一评估相关性，不纳入的类别须说明排除理由 |
| 上下游边界清晰 | 明确上游（采购、供应商）与下游（分销、使用、报废）边界，不与范围 1/2 交叉重复 |
| 重要性评估有据 | 纳入类别的选择基于排放占比、业务重要性、数据可得性综合评估，有书面依据 |
| 时间与组织边界一致 | 范围3 核算年度与范围 1/2 一致，组织边界（股权比例 / 控制权）匹配 |
| 双重计算防控 | 明确与供应链上下游企业数据的划分边界，避免同一排放被多家企业重复计入 |

## 二、数据质量与核算方法
| 检查项 | 通过标准 |
|--------|----------|
| 数据层级标注清晰 | 一级数据（供应商实测）、二级数据（行业平均）、三级数据（支出法）区分明确并标注 |
| 核算方法选择合理 | 优先使用活动数据法，数据不足时使用支出法 / 平均数据法，方法选择有说明 |
| 排放因子匹配度 | 排放因子与采购品类、行业、地区尽可能匹配，避免跨行业、跨地区粗放套用 |
| 数据覆盖率可查 | 采购金额 / 活动数据覆盖率有统计（如：已覆盖采购总额的 XX%），并说明缺口处理 |
| 单位换算正确 | 支出金额、重量、里程、耗电量等单位与排放因子单位对应，换算系数有来源 |

## 三、供应商数据管理
| 检查项 | 通过标准 |
|--------|----------|
| 数据收集模板规范 | 向供应商发放的数据收集表格式统一、口径明确、含填报说明 |
| 供应商数据验证 | 高排放重点供应商的数据有交叉验证或第三方核查支撑（如有） |
| 隐私与数据安全 | 供应商商业数据与排放数据的保密措施到位，符合数据合规要求 |
| 分级管理清晰 | 按排放贡献与战略重要性对供应商分级，不同级别数据与减排要求差异化 |

## 四、报告与披露
| 检查项 | 通过标准 |
|--------|----------|
| 方法学透明披露 | 核算方法、数据来源、假设条件、不确定性在报告中充分说明 |
| 结果按类别拆分 | 范围3 排放按 15 类分项列示，不合并模糊呈现 |
| 年度趋势可比 | 多年数据时核算方法与边界保持一致，方法变更时说明影响并做重述 |
| 热点识别聚焦 | 识别出 Top10 供应商或 Top 采购品类排放，作为减排管理重点 |

## 五、减排行动与持续改进
| 检查项 | 通过标准 |
|--------|----------|
| 减排目标传导 | 范围3 减排目标与供应商减排要求挂钩，有明确的传导机制 |
| 绿色采购标准 | 采购制度中融入碳绩效要求（如供应商碳数据披露、碳标签、绿色门槛） |
| 能力建设支持 | 对重点供应商提供碳核算与减排培训或技术支持 |
| 进度跟踪机制 | 每年跟踪范围3 排放变化与供应商减排进展，定期更新核算结果 |
