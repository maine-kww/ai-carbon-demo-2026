# Supply Chain Carbon  供应链碳管理（范围3）

## Overview

核算并管理企业价值链上下游的温室气体排放（范围3），识别减排重点环节，支持绿色采购与供应链披露。核心：识别范围3类别 → 核算 → 供应商数据收集 → 减排与采购策略。范围3数据常为估算，须透明标注方法。

本 Skill 为**数据驱动模式**：行业规则、燃料/能源类范围3排放因子、支出法因子来源、披露政策依据一律从 `data/` 数据层动态查询，不在本文件写死具体因子数值或政策年份。

## 数据层（核算前必读）

行业规则、燃料/能源类范围3排放因子、披露政策依据均从 `data/` 数据层动态查询，**不在本文件写死具体因子数值或政策年份**。支出法因子数据层未收录时回退 references 并标注。

| 内容 | 数据文件 | 统一查询命令 |
|---|---|---|
| 行业规则表（上游行业核算标准） | `data/industry/industry_rules.json` | `python data/scripts/query_data.py get-industry <行业名>` |
| 政策元数据表（范围3披露政策、绿色采购政策） | `data/policy/policy_metadata.json` | `python data/scripts/query_data.py search-policy <关键词>` |
| 电网排放因子库 | `data/factors/grid_electricity_factors.json` | `python data/scripts/query_data.py get-grid-factor --year <年份> --region <区域>` |
| 化石燃料因子库 | `data/factors/fossil_fuel_factors.json` | `python data/scripts/query_data.py get-fuel-factor <燃料类型>` |
| 数据版本号 | — | `python data/scripts/query_data.py version` |

> 运行路径：在 `carbon-md/` 根目录下执行上述命令。

数据状态约定：数据层每条记录含 `confidence` 或 `status` 字段，引用时必须透传，不得把估算/占位当已查证输出。支出法因子数据层未收录时，回退 `references/scope3-guide.md` 并标注"legacy 回退/估算"。
## Workflow

### 1. 识别范围3类别与核算主体行业
- 按 GHG Protocol 范围3 15类识别适用类别：外购商品/服务、上游运输、燃料和能源相关活动、商务旅行、下游运输、产品使用/报废、投资等。
- 确定需纳入的类别与重要性（排放占比/风险）；确定核算主体所属行业与报告期；先执行 `python data/scripts/query_data.py list-industries` 查看已覆盖行业，若行业不在数据层中则标注估算口径。

### 2. 从行业规则表与政策表查询规则（get-industry + search-policy）
- 执行 `python data/scripts/query_data.py get-industry <上游行业名>`，获取上游主要供应商所在行业的核算标准、排放因子来源、是否覆盖间接排放，指导范围3类别3（燃料和能源相关活动）的衔接口径，避免与范围1/2重复计算。
- 执行 `python data/scripts/query_data.py search-policy 披露/范围3/绿色采购, 适用行业=...)`，获取适用的披露要求与绿色采购政策，记录政策依据文号、发文机关与日期。

### 3. 从排放因子库查询因子
- 活动数据法：按 行业/年份/能源类型(item)/地区 根据因子类别选择相应命令（get-fuel-factor / get-grid-factor / get-process-factor），类别3（能源相关活动）与上游运输的电力/燃料因子优先从数据层取（英文 fuel_type 直接命中中文能源类型）。
- 支出法：采购品类的支出型因子数据层未收录时，回退 `references/scope3-guide.md` 与权威 IO/USEEIO 背景值，并在输出标注"legacy 回退/估算"。
- 多条命中优先"已查证"记录；缺失数据用缺省因子估算并标注。

### 4. 数据收集与核算（scripts/scope3_calc.py）
- 一级：供应商提供活动数据或排放数据；次级：用行业/支出法（支出×排放因子）估算。
- 用 `scripts/scope3_calc.py` 按类别汇总（活动数据法/支出法）。行内显式因子 → 直接使用（兼容原行为，标注 legacy/手动）；未给出时用 `--industry / --year / --region` 自动从数据层查询填充。

### 5. 输出、标注与披露（必做）
- 识别热点与风险：找出排放占比最高的供应商/采购品类，结合碳价与政策预期评估供应链气候风险（衔接 `carbon-policy`）。
- 在输出中标注：**核算/披露标准版本**、**因子来源**（机构 + 年份 + 版本 + 数据状态）、**政策依据的文号和日期**、数据状态（已查证/估算/占位-待核实）。
- 按披露框架（衔接 `carbon-esg`）组织范围3披露；交付：核算表走 `sheet`，策略说明走 `lark-doc`/`word`，占比可视化配合 `doubao-visualization`。

## 规范
- 范围3 多依赖估算，须注明方法（活动数据/支出法）、数据来源与不确定性。
- 避免与范围1/2及供应链上下游重复计算。
- 供应商数据缺失时用缺省因子估算并标注。

### 质量保证与数据规范
- **边界清晰原则**：范围3 与范围 1/2 之间、与上下游企业之间不重复计算，边界划分有明确说明。
- **数据分级原则**：明确一级（供应商实测）、二级（行业平均）、三级（支出法）数据层级，优先使用更高层级数据。
- **方法透明原则**：每个类别使用的核算方法、排放因子来源、关键假设全部公开，便于使用者理解不确定性。
- **覆盖渐进原则**：范围3 数据难以一步到位，应从高排放类别开始逐步提高覆盖率，而非追求一开始就完美。
- **年度一致原则**：多年数据对比时，核算方法与边界保持一致；若有变更，须说明影响并视情况重述历史数据。
- 完成范围3 核算或供应链碳管理方案后，应使用 `references/quality-checklist.md` 逐项自检，通过后方可输出。

### 来源与引用规范
- 范围3 排放因子、行业数据、IO 表均需标注来源（机构、数据库名、版本、年份）；优先引用数据层透传的 `来源/文号/数据状态`。
- **供应商提供数据**与**基于因子的估算数据**严格区分，估算值标注"【估算】"并说明方法。
- 引用优先级：GHG Protocol 官方指南 > 政府主管部门发布的因子与指南 > 权威数据库（EPA / Ecoinvent / 国家统计局）> 行业协会报告 > 咨询机构估算 > 学术文献。
- 支出法因子应匹配采购品类的行业分类，避免跨行业粗放套用导致较大误差。
- 标准与数据来源的历史清单参见 `references/standards-sources.md`（历史参考，以数据层为准）。

### 边界与免责
- 本 Skill 提供范围3 核算方法论与供应链碳管理框架指导，核算结果因数据可得性限制存在较大不确定性。
- 本 Skill 不构成法律、合规或投资建议；企业范围3 披露能否满足 CSRD、CDP 等要求，以相关机构审核为准。
- 本 Skill 不对供应商提供数据的真实性负责，供应商数据质量直接影响范围3 结果准确性。
- 范围3 排放因子数据库存在区域差异与时效性问题，同一企业不同年份的核算结果可能因因子更新而变化。
- 涉及供应商数据收集与管理时，应遵守数据安全、个人信息保护、商业秘密保护等法律法规。
