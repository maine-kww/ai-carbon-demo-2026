# 碳交易与配额管理质量检查清单

本清单用于碳交易与配额测算完成后的质量自检，确保输出数据准确、逻辑合理、风险充分披露。

---

## 一、数据质量检查

| 检查项 | 通过标准 |
|---|---|
| 排放量数据来源明确 | 注明是核算报告值/核查值/预估值，以及对应年份 |
| 配额数据类型清晰 | 区分预分配/最终核定/结转，并有依据 |
| 碳价数据有时点 | 每条价格标注市场、日期、价格类型（收盘价/均价） |
| CCER 抵消比例正确 | 按当年最新规则，注明规则来源与适用市场 |
| 单位统一 | 全部使用 tCO2e（排放量）、元/吨（价格）、万元（金额） |
| 数据时效性 | 使用最近可用价格，避免使用 3 个月以上的行情 |

---

## 二、测算逻辑检查

| 检查项 | 通过标准 |
|---|---|
| 缺口公式正确 | 缺口 = 核查排放量 − 实际持有配额 − 可抵消 CCER |
| 抵消上限合规 | CCER 抵消比例不超过规定上限（全国碳市场 5%/履约期） |
| 情景分析完整 | 至少提供保守情景和乐观情景两组测算 |
| 敏感性分析合理 | 碳价 ±10%/±20% 对成本的影响已说明 |
| 成本测算全面 | 包含配额采购成本 + 交易手续费 + CCER 成本（如有） |
| 结转规则正确 | 区分可用结转量和不可用部分，注明规则依据 |

---

## 三、策略分析检查

| 检查项 | 通过标准 |
|---|---|
| 策略选项清晰 | 给出买入/卖出/持有/分期等明确选项 |
| 每个选项有依据 | 每个策略选项都有数据支撑和逻辑说明 |
| 风险因素覆盖 | 包含政策风险、价格风险、流动性风险、合规风险 |
| 时间维度考虑 | 策略结合履约截止日期和市场时间节点 |
| 不做绝对判断 | 策略表述为"建议""可考虑"，不使用"一定会涨""必须买入" |
| 与客户场景匹配 | 策略符合企业类型（控排企业/投资机构/减排项目方） |

---

## 四、合规与披露检查

| 检查项 | 通过标准 |
|---|---|
| 不构成投资建议 | 输出中明确声明"不构成投资建议或交易指令" |
| 风险提示完整 | 5 类风险至少简要提及（政策/价格/数据/合规/流动性） |
| 假设全部列示 | 测算假设明确列出，用户可自行调整 |
| 来源可追溯 | 规则、价格、数据均有来源标注 |
| 重大决策提示 | 涉及大额交易时提示咨询专业机构 |
| 合规边界清晰 | 不替代企业合规部门的最终判断 |

---

## 五、输出格式检查

| 检查项 | 通过标准 |
|---|---|
| 结构完整 | 场景 → 数据 → 测算 → 策略 → 风险，五段齐全 |
| 数字突出 | 关键数字（缺口量、成本、碳价）醒目易找 |
| 表格清晰 | 测算结果以表格形式呈现，便于核对 |
| 结论前置 | 开头有一句话总结，结尾有核心建议 |
| 单位标注 | 所有数字均有单位（tCO2e、元、元/吨） |
| 无歧义表述 | 避免"大概""可能""左右"等模糊词用在关键数字上 |
