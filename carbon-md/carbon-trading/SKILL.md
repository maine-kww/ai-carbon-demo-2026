# Carbon Trading 碳交易与配额管理

## Overview

围绕碳配额（CEA）与自愿减排量（CCER）的管理与交易决策，提供履约缺口测算、交易成本分析、碳价行情跟踪与策略评估。核心产出：缺口/盈余测算 → 成本收益 → 交易策略建议。

本 Skill 为**数据驱动模式**：配额分配方法（强度法/基准线法，随行业记录）、适用配额方案文号与日期、CCER 抵消比例上限一律从 `_data/` 数据层查询，不在本文件写死行业配额规则。

## 数据层（测算前必读）

所有行业配额规则、政策依据均从 `_data/` 数据层动态查询，**不在本 Skill 中写死任何行业配额参数**。

| 内容 | 数据文件 | 统一查询命令（在 `carbon-md/` 下运行） |
|---|---|---|
| 行业配额规则 | `_data/industry_rules.json` | `python _data/query.py industry --name <行业名>`（或 `industry <行业代码>` 如 `steel`） |
| 配额方案政策 | `_data/policy_meta.json` | `python _data/query.py policy --keyword 配额方案 --type 配额方案 --industry <行业名>` |
| 全部政策清单 | `_data/policy_meta.json` | `python _data/query.py policy`（不带过滤条件即返回全部） |
| 三表统计/版本 | — | `python _data/query.py stats` |

> 脚本内统一接入方式：`sys.path.insert(0, str(Path(__file__).resolve().parents[2] / "_data"))` + `from query import query_industry, query_policy, query_factor`。

关键字段映射（行业规则表 `industry_rules.json`，中文字段）：
- 配额分配方法 → `配额分配方法`（强度法/基准线法免费分配，随行业记录，非写死）
- 是否覆盖间接排放 → `是否覆盖间接排放`
- 纳入碳市场时间 → `纳入碳市场时间`
- 数据状态 → `数据状态`（已查证 / 估算 / 占位-待核实）
- CCER 抵消比例 → 不在行业表，须查政策表 `policy --type 配额方案` 的 `结构化摘要`（如发电行业"CCER抵销比例不超过应清缴量5%"）

## Workflow

### 1. 明确场景与行业
- 确认是控排企业履约测算、减排项目 CCER 开发评估、还是配额投资/交易决策。
- 确认主体所在**行业**（发电/钢铁/水泥/铝冶炼/…）、所在市场（全国碳市场 / 地方试点）与履约周期年度。

### 2. 收集基础数据
- 排放量（来自核算报告）、分配配额、已购/结转配额、减排量。
- 碳价行情：通过 `seed_finance_lookup` 或 `general_search` 查询全国碳价与地方试点行情；注明价格时间点。

### 3. 从数据层查询配额规则
- 执行 `python _data/query.py industry --name <行业名>`（或 `industry <行业代码>`），获取该行业的**配额分配方法**（强度法/基准线法或总量控制）、是否覆盖间接排放、纳入时间、数据状态等。
- 执行 `python _data/query.py policy --keyword <行业名> --type 配额方案`，从政策元数据表查询适用的配额方案、管理条例等**政策依据**（文号、发布日期、时效状态）；CCER 抵消比例从配额方案的 `结构化摘要` 提取。
- 行业不在数据层或未纳入碳市场：标注"该行业未纳入碳市场/数据层暂未覆盖"，`quota_calc.py` 走 legacy 回退模式并提示人工核对当年最新配额方案。

### 4. 履约缺口测算（scripts/quota_calc.py）
- 使用 `scripts/quota_calc.py` 测算：缺口 = 排放量 − 配额（已持有）− 可抵消 CCER。
- 数据驱动模式：传入 `--industry 行业 [--year 年度]`，脚本自动从数据层读取配额分配方法与 CCER 抵消比例；显式 `--ccer-limit` 优先于数据层。
- 输出缺口量、预计采购成本、或富余可售收益，并附数据层标注（配额方案文号/日期/数据状态）。

### 5. 策略分析
- 依据 `references/trading-guide.md` 做买入/卖出/持有评估，考虑价格走势、履约时点、结转规则。
- 结合数据层查询到的配额方案政策与 `references/market-rules.md`（carbon-policy）核对交易与抵消规则。

### 6. 输出决策支持（含标注）
- 结构：场景 → 数据 → 测算结果 → 策略选项（含成本/收益）→ 风险与不确定性 → **政策依据标注**（配额方案文号、发布日期、数据状态）。
- 交付：测算表走 `sheet`，决策说明走 `lark-doc`/`word`，行情/结构可视化配合 `doubao-visualization`。

## 质量保证与数据规范

### 核心质量原则
- 本 Skill 提供**测算与决策支持**，不构成投资建议、交易指令或履约承诺。
- 所有价格、配额、抵消比例数据均须注明时间点和来源，不得使用模糊的"市场价"表述。
- 涉及真实资金决策时，必须提醒用户确认合规要求与财务风险，重大交易建议咨询合规与财务专业人士。

### 数据质量要求
- **碳价数据**：必须标注日期、市场（全国/地方试点）、价格类型（收盘价/均价）。
- **配额数据**：区分"预分配"和"最终核定"，两者可能有差异。
- **排放量数据**：引用 `carbon-accounting` 的核算结果，注意"报告排放量"和"核查后排放量"可能有出入。
- **CCER 抵消比例**：不同履约期、不同市场的抵消上限可能不同，须按当年最新规则核算。

### 测算规范
- **保守原则**：缺口测算时，排放量用上限、配额用下限，偏保守地估算缺口。
- **情景分析**：给出至少 2 种情景（乐观/保守）的测算结果，而非单一数字。
- **敏感性分析**：对碳价、排放量等关键变量做简单敏感性分析，说明变量波动对结果的影响。
- **单位统一**：全部使用 tCO2e 和元/吨，避免单位混淆。

### 风险提示清单
每次输出交易策略时，必须包含以下风险提示（可用简要形式）：
1. **政策风险**：配额分配规则、抵消比例、纳入行业范围可能调整。
2. **价格风险**：碳价受政策、供需、宏观经济等多重因素影响，波动较大。
3. **数据风险**：测算基于输入数据，实际以官方核查结果为准。
4. **合规风险**：交易主体资格、交易方式须符合监管要求。
5. **流动性风险**：部分时段成交量低，大额交易可能影响价格。

完成交易策略分析后，应使用 `references/quality-checklist.md` 做全面自检，确保数据准确、逻辑合理、风险充分披露。

## 来源与引用规范

### 引用优先级
1. 官方文件：生态环境部政策法规、交易所交易规则、履约通知
2. 交易所数据：上海环交所、各试点交易所的正式行情数据
3. 权威研究：专业碳咨询机构的研究报告
4. 媒体报道：仅作为补充参考，不用于关键结论

### 引用格式
- 碳价引用格式：`[市场, 日期] 价格 元/吨`，如 `[全国碳市场, 2024-12-31] 收盘价 95.3 元/吨`。
- 规则引用格式：注明发布机构、文件名称、发布年份。
- 所有测算假设必须明确列出，让用户可以根据自己的判断调整。

详细标准与数据来源索引见 `references/standards-sources.md`。

## 边界与免责

### 不做什么
- 不提供实盘交易指令，不代用户下单操作
- 不预测碳价未来走势的确定性结论，仅做情景分析
- 不替代企业合规部门的履约判断与法律责任
- 不提供税务、法律、财务等专业领域的最终意见
- 不对交易盈亏做出任何保证或承诺

### 免责声明
- 本 Skill 的测算结果仅供决策参考，不构成投资建议、交易指令或履约承诺。
- 碳市场政策、规则、价格处于动态变化中，以官方最新发布为准。
- 用户应基于自身情况独立判断，重大交易决策建议咨询专业机构。
- 因使用本 Skill 输出内容导致的任何损失，由用户自行承担。
