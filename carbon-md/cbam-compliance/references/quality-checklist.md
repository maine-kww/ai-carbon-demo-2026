# CBAM 碳关税申报与核查应对质量检查清单

## 一、适用性判断
| 检查项 | 通过标准 |
|--------|----------|
| 产品归类准确 | 出口产品按 CN 编码与 CBAM 附录产品清单对照，归类准确，不遗漏适用产品 |
| 申报义务识别清晰 | 明确申报人身份（进口商 / 间接申报人 / 授权代表），注册义务按时履行 |
| 过渡期 / 正式期区分 | 清楚当前所处阶段（过渡期报告义务 / 正式期证书义务），适用规则正确 |
| 豁免情形核实 | 若主张豁免（如加工贸易、再出口、低排放阈值等），有充分依据与证明材料 |
| 覆盖气体完整 | 纳入 CBAM 规定的全部温室气体种类（CO2 为主，部分产品含 N2O、PFCs 等） |

## 二、隐含排放核算
| 检查项 | 通过标准 |
|--------|----------|
| 核算边界正确 | 直接排放（生产过程）+ 特定间接排放（外购电力 / 蒸汽 / 热力等）符合 CBAM 规定 |
| 生产流程完整 | 产品生产的所有相关工艺步骤均纳入，不遗漏高排放工序 |
| 排放因子匹配 | 实测排放因子优先，缺省值使用符合 CBAM 实施条例规定的默认值与使用条件 |
| 分配方法合规 | 多产品共用设施的排放分配方法（质量 / 能量 / 产量法）符合 CBAM 规则且前后一致 |
| 核算单位一致 | 隐含排放以每吨产品 CO2e 为单位，与产品计量单位匹配，换算正确 |

## 三、申报数据与证据
| 检查项 | 通过标准 |
|--------|----------|
| 活动数据来源可查 | 燃料消耗、电力使用、原材料用量、产量等数据有计量记录、票据、生产报表支撑 |
| 排放数据可追溯 | 排放计算过程、因子来源、分配系数全部留痕，可从结果追溯到原始数据 |
| 申报信息完整 | 申报系统要求的所有字段（企业信息、产品信息、排放量、证据文件）完整提交 |
| 报告周期合规 | 过渡期按季度报告，正式期按年度申报，截止日期前完成提交 |
| 数据一致性 | CBAM 申报数据与企业碳核算、环境报告、能耗统计数据口径一致，差异有解释 |

## 四、核查准备
| 检查项 | 通过标准 |
|--------|----------|
| 核查机构资质确认 | 如需第三方核查，核查机构在欧盟认可的核查机构名录内 |
| 核查资料准备齐全 | 排放报告、计算工作簿、原始数据、计量校准证书、工艺流程图等全部备齐 |
| 现场核查条件 | 生产现场、计量点、监测设备可访问，相关人员可配合问询 |
| 不符合项应对机制 | 核查中发现的问题有快速响应、补正与整改流程 |

## 五、合规策略与风险
| 检查项 | 通过标准 |
|--------|----------|
| 碳成本评估 | 已评估 CBAM 对产品成本、出口价格、利润的影响 |
| 数据质量提升计划 | 针对当前使用缺省值的部分，有提升实测数据比例的时间表与路线图 |
| 减排路径规划 | 识别关键减排措施，评估减排对降低 CBAM 成本的贡献 |
| 供应链风险评估 | 上游原材料 / 能源供应的碳数据可得性与合规风险已评估 |
| 政策跟踪机制 | 建立 CBAM 规则更新（覆盖范围扩展、方法学修订）的跟踪与应对机制 |
