# 政策法规来源索引

> 检索技巧与注意事项见 `source-guide.md`，本文件聚焦"有哪些来源、各管什么"。

## 二、地方级官方来源

### 地方政府与部门
- **省级人民政府官网**：各省/自治区/直辖市政府官网 → 政策文件栏目
- **地方生态环境厅/局**：各省市生态环境厅（局）→ 应对气候变化处/科、大气环境处
- **地方发改委**：各省市发展改革委 → 资源节约和环境保护处、气候处
- **地方工信厅/局**：工业节能、绿色制造相关文件

## 三、行业主管部门与协会

### 行业主管
- **国家能源局**：www.nea.gov.cn — 能源政策、电力行业、可再生能源
- **国家矿山安全监察局**：煤炭行业相关
- **国家林业和草原局**：www.forestry.gov.cn — 林业碳汇、生态保护修复

### 行业协会
- **中国电力企业联合会（中电联）**：www.cec.org.cn — 电力行业统计、电网排放因子
- **中国钢铁工业协会**：www.cisa.org.cn — 钢铁行业碳达峰、行业基准
- **中国建筑材料联合会**：www.cbmf.org — 水泥、玻璃等建材行业
- **中国石油和化学工业联合会**：www.cpcia.org.cn — 化工行业
- **中国造纸协会**：www.chinappi.org — 造纸行业

> 行业协会发布的数据和指南可作参考，但**不能替代官方政策**。引用时须明确为行业协会来源。

## 四、国际组织与公约

### 气候公约与国际机构
| 组织 | 官网 | 核心内容 |
|------|------|---------|
| UNFCCC（联合国气候变化框架公约） | unfccc.int | 国际气候谈判、巴黎协定、国家自主贡献（NDC） |
| IPCC（政府间气候变化专门委员会） | ipcc.ch | 评估报告、方法学指南、排放因子、GWP 值 |
| ISO（国际标准化组织） | iso.org | ISO 14064、ISO 14067 等气候相关标准 |
| 世界银行（World Bank） | worldbank.org | 碳定价机制、气候融资 |
| IEA（国际能源署） | iea.org | 全球能源与排放数据、情景分析 |

### 国际碳市场机制
- **清洁发展机制（CDM）**：cdm.unfccc.int（已进入过渡期）
- **自愿碳市场（VCM）**：Verra（verra.org）、Gold Standard（goldstandard.org）等

## 引用格式速查

```
# 国家级政策
《关于完整准确全面贯彻新发展理念做好碳达峰碳中和工作的意见》（中发〔2021〕36 号）
《2030 年前碳达峰行动方案》（国发〔2021〕23 号）
《碳排放权交易管理办法（试行）》（生态环境部令第 19 号）

# 部门规范性文件
《企业温室气体排放核算方法与报告指南 发电设施》（2022 年修订版）
《全国碳排放权交易市场第一个履约周期配额分配方案》（环办气候函〔2021〕XXX 号）

# 地方政策
《XX省碳达峰实施方案》（XX 省人民政府，2022 年 X 月发布）

# 国际标准/公约
《巴黎协定》（UNFCCC，2015 年签署，2016 年生效）
ISO 14064-1:2018 组织层面温室气体排放的量化和报告
```

> ⚠️ **铁律**：政策文件必须以发布机构官网的正式文本为准。新闻报道、公众号解读、第三方平台转载只能作为辅助理解，绝不能作为引用依据。
