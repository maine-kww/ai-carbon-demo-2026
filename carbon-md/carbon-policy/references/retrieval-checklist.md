# 政策检索与解读质量检查清单

> 完成政策检索和解读后逐项检查，确保来源可靠、解读准确、表述规范。

## 一、来源可靠性

- [ ] **政策原文已获取**：不是二手报道或解读，是官方发布的正式文本
- [ ] **来源渠道权威**：来自发布机构官网或官方法规数据库
- [ ] **文号已记录**：能说出完整的发文机构 + 文号
- [ ] **发布日期已确认**：具体到年月日
- [ ] **生效日期已确认**：知道什么时候开始施行、是否有过渡期
- [ ] **时效性已核实**：
  - [ ] 当前版本是否仍然有效
  - [ ] 是否有修订或补充通知
  - [ ] 是否有被新政策替代

## 二、政策信息完整性

- [ ] **政策名称完整准确**：使用正式全称，不是简称或俗称
- [ ] **发布层级清楚**：法律 / 行政法规 / 部门规章 / 规范性文件 / 地方规定
- [ ] **发布机构准确**：发文机关全称，不只是"有关部门"
- [ ] **适用范围明确**：哪些行业、哪些地区、哪些主体适用
- [ ] **核心条款已提取**：对用户有直接影响的关键条款都找到了
- [ ] **配套文件已关注**：实施细则、技术指南、问答等配套文件是否存在

## 三、解读准确性

- [ ] **区分了事实和判断**：
  - [ ] 政策原文内容 = 事实（引用原文）
  - [ ] 影响分析 = 判断（标注"分析认为"）
- [ ] **没有过度解读**：政策没说的不脑补、不延伸
- [ ] **不确定项标注了"待核"**：存疑的地方明确说出来，不装懂
- [ ] **引用了具体条款**：每个要点都有对应的条款号或章节名
- [ ] **没有断章取义**：引用的原文是完整语境下的，不是掐头去尾

## 四、用户相关性

- [ ] **针对用户主体分析**：不是泛泛而谈，而是结合用户的行业/地区/身份
- [ ] **区分了直接影响和间接影响**
- [ ] **合规义务清单具体**：用户需要做什么、什么时候做、找谁做
- [ ] **时间节点明确**：有具体的 deadline，不是"近期""未来"
- [ ] **风险提示到位**：不遵守的后果是什么（罚款/信用/市场准入）

## 五、输出规范

- [ ] **结构清晰**：政策概况 → 核心要点 → 影响分析 → 行动清单
- [ ] **术语准确**：专有名词使用正确，解释清楚
- [ ] **免责声明已包含**：不构成法律意见，建议咨询专业机构
- [ ] **时效提醒已标注**：解读基于 XX 年 XX 月公开信息
- [ ] **来源链接已附上**：官方原文链接方便用户回查

## 六、常见错误检查

- [ ] 把征求意见稿当成正式文件
- [ ] 用了已经废止的旧政策
- [ ] 把 A 省的政策套到 B 省用户头上
- [ ] 混淆"部门规章"和"规范性文件"的法律效力
- [ ] 只说"政策利好"，不说具体利好什么、利好多少
- [ ] 把媒体解读当政策原文引用
- [ ] 政策名称说一半，用户查不到原文
- [ ] 没有区分"强制义务"和"鼓励方向"

> 💡 **自检方法**：把解读结果拿给一个"不懂政策的人"看，如果他能根据你的输出：
> 1. 找到政策原文
> 2. 明白政策说的是什么
> 3. 知道自己该做什么
>
> 那就是合格的解读。
