# 政策检索与解读质量自检清单

> 完成政策检索和解读后，从以下五个维度逐项自检，确保来源可靠、解读准确、表述客观。
> 本清单聚焦质量控制环节，检索执行与输出格式检查见 `retrieval-checklist.md`。

## 一、来源权威性

- [ ] **引用自官方原文**：所有政策条款均来自发布机构官网或官方法规数据库，未使用媒体报道、公众号文章、第三方解读作为引用依据
- [ ] **发文渠道为最高层级**：同一政策有多个转载来源时，使用发布机构官网原文作为引用源，而非下级单位或媒体转载
- [ ] **文号完整准确**：能说出完整的发文机构 + 文号（如"发改气候〔2022〕XXX 号"），不是只有俗称或简称
- [ ] **发布机构层级清楚**：准确区分法律 / 行政法规 / 部门规章 / 规范性文件 / 地方规定，不混淆法律效力层级
- [ ] **配套文件已核实**：实施细则、技术指南、问答、解读等配套文件均从官方渠道获取，不是二手版本

## 二、时效性

- [ ] **发布日期与生效日期均已确认**：具体到年月日，知道政策何时发布、何时施行、是否有过渡期
- [ ] **当前有效性已核实**：通过搜索"修订""修改""废止""替代"等关键词，确认政策当前仍然有效
- [ ] **最新版本已采用**：使用的是最新修订版，不是已被替代的旧版本
- [ ] **适用期限已标注**：对于有明确执行期限或适用期的政策（如年度配额分配方案），已在解读中注明
- [ ] **时效提醒已包含**：输出中标注"解读基于 XX 年 XX 月公开信息"，提醒用户核实最新版本

## 三、准确性

- [ ] **政策名称使用正式全称**：不是简称或俗称，用户能凭名称直接检索到原文
- [ ] **引用条款有原文依据**：每个核心要点都能对应到具体条款号或章节名，不是凭空归纳
- [ ] **引用语境完整**：引用的原文是完整语境下的，不是掐头去尾、断章取义
- [ ] **没有过度解读**：政策没明确说的内容不脑补、不延伸，不把"鼓励"说成"强制"
- [ ] **数字和日期准确**：涉及的数量、比例、日期、金额等数字均与原文一致，无转录错误

## 四、完整性

- [ ] **核心条款无遗漏**：对用户主体有直接约束的关键条款（配额、核算、MRV、履约、处罚等）均已提取
- [ ] **适用范围明确**：清楚说明哪些行业、哪些地区、哪些主体适用，哪些不适用
- [ ] **配套文件已关注**：实施细则、技术指南、问答、通知等配套文件是否存在已核实，重要配套已纳入解读
- [ ] **地方差异已考虑**：对于地方政策，明确了适用地域范围，不把 A 省政策套到 B 省
- [ ] **罚则与责任已提取**：不遵守的法律后果（罚款/信用/市场准入/刑事责任）已说明，方便用户评估风险

## 五、解读客观性

- [ ] **事实与判断严格区分**：政策原文内容 = 事实（引用原文），影响分析 = 判断（标注"分析认为"），两者分开陈述
- [ ] **不确定项标注"待核"**：存疑或有歧义的条款明确标注，不装懂、不强行给出结论
- [ ] **多角度呈现**：对有争议或多种解读可能的条款，说明不同理解，不只讲一种
- [ ] **不代入主观立场**：解读不偏向任何一方利益，客观呈现政策要求和影响，不做"利好/利空"的简单定性
- [ ] **免责声明到位**：明确说明不构成法律意见或合规保证，重大决策建议咨询专业律师

> 💡 **自检方法**：把解读结果拿给一个"不懂政策的人"看，如果他能：① 找到政策原文 ② 明白政策说什么 ③ 知道自己该做什么，那就是合格的解读。
