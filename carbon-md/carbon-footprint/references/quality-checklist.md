# 产品碳足迹核算质量检查清单

## 一、目标与范围定义
| 检查项 | 通过标准 |
|--------|----------|
| 功能单位明确 | 功能单位（如 1 kg 产品、1 件成品、1 kWh 电力）清晰定义，且全核算过程一致 |
| 产品系统边界清晰 | 明确摇篮到大门 / 摇篮到坟墓 / 大门到大门，各生命周期阶段纳入/排除有依据 |
| 核算气体种类完整 | 包含 CO2、CH4、N2O、HFCs、PFCs、SF6、NF3 全部 GHG Protocol 规定气体 |
| 时间边界合理 | 报告期与数据采集周期一致，一般不少于连续 12 个月 |
| 地理与技术边界明确 | 生产所在地、工艺路线、技术水平有说明，不混淆不同地区数据 |

## 二、数据质量
| 检查项 | 通过标准 |
|--------|----------|
| 初级数据占比可查 | 现场实测 / 计量 / 票据等初级数据有明确来源，占比符合相关标准要求 |
| 次级数据来源标注 | 背景数据库（Ecoinvent、CLCD、中国生命周期数据库等）版本号、年份、区域信息完整 |
| 排放因子时效性 | 使用近 5 年内发布的排放因子；中国数据优先采用最新省级电网因子、国家或行业指南 |
| 数据完整性检查 | 关键排放源（贡献前 80%）无遗漏；次要排除项需说明理由 |
| 数据单位与换算正确 | 活动数据单位与排放因子单位匹配，换算有依据（如低位热值、标煤折算） |

## 三、方法与计算
| 检查项 | 通过标准 |
|--------|----------|
| 分配方法合理 | 多产品共用过程采用质量 / 能量 / 经济价值分配，且方法选择有说明并前后一致 |
| 温室效应潜势（GWP）版本正确 | 明确使用 IPCC AR5 或 AR6 版本 GWP 值，不混用 |
| 取舍规则一致 | 截断标准（如 1% 或 5% 阈值）有明确声明，排除项对总量影响可评估 |
| 计算过程可复现 | 公式、参数、数据链条可追溯，中间步骤保留可核查 |

## 四、报告与文档
| 检查项 | 通过标准 |
|--------|----------|
| 报告结构符合标准 | 包含目标与范围、LCI 方法、LCIA 结果、解释说明四大部分 |
| 不确定性分析 | 至少做定性或半定量不确定性说明，关键敏感参数影响有讨论 |
| 版本与修订记录 | 报告版本号、修订日期、变更说明齐全 |
| 假设与估算标注 | 所有估算值、默认值、假设条件明确列出且不与实测数据混淆 |

## 五、合规与风险
| 检查项 | 通过标准 |
|--------|----------|
| 标准一致性 | 声明遵循的标准（ISO 14067 / PAS 2050 / 国标）条款匹配，无方法冲突 |
| 第三方核查要求 | 若用于认证 / 标签 / 披露，已按要求准备核查资料或委托具备资质机构 |
| 数据来源合法 | 初级数据来自企业授权，次级数据来自合规数据库（注意版权与授权） |
