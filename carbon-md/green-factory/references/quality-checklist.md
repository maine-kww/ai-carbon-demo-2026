# 绿色工厂/绿色园区申报质量检查清单

> 历史参考，以 _data 数据层为准（2026-10-09）：清单涉及的零碳工厂培育范围与政策依据（工信部联节〔2026〕13号）以 `_data` 数据层查询结果为准；本清单为交付前自检框架。

## 一、申报基础条件
| 检查项 | 通过标准 |
|--------|----------|
| 主体资格合规 | 申报主体为依法设立的企业/园区管委会，近三年无重大安全、环保、质量违法记录 |
| 符合产业政策 | 不属于国家产业结构调整指导目录限制类、淘汰类范畴 |
| 申报级别匹配 | 国家级绿色工厂需先获省级认定，园区具备明确地理边界与管理主体 |
| 申报期内信用良好 | 未列入失信被执行人名单，未发生重大环境污染事故 |
| 申报材料真实性承诺 | 法定代表人签字、公章齐全，数据真实性承诺函完备 |

## 二、评价指标维度
| 检查项 | 通过标准 |
|--------|----------|
| 基础设施指标完整 | 建筑、照明、用水、用能、通用设备等基础设施绿色化指标全部覆盖，有数据支撑 |
| 管理体系认证齐全 | ISO 9001 / ISO 14001 / ISO 45001 / ISO 50001 等体系认证在有效期内 |
| 能源资源投入指标达标 | 单位产品能耗、单位产值能耗、单位产品水耗等关键指标达到行业先进值或标准要求 |
| 产品指标符合要求 | 绿色设计产品、有害物质替代、产品能效等级、可回收利用率等指标有证明 |
| 环境排放指标达标 | COD、氨氮、SO2、NOx、VOCs 等污染物排放达标，总量控制完成，碳排放有核算 |
| 绩效指标领先 | 单位产值碳排放、单位产品碳排放、绿色产值占比等绩效指标处于行业先进水平 |

## 三、证明材料
| 检查项 | 通过标准 |
|--------|----------|
| 证明材料对应性 | 每个自评指标项均有对应的证明材料（证书、报告、台账、照片等） |
| 能耗数据来源可靠 | 能源消费数据来自计量器具、缴费单据、能源审计报告，与碳核算数据一致 |
| 排放数据可核查 | 污染物排放数据来自监测报告、在线监测、环保部门核定数据 |
| 第三方报告有效 | 能源审计、清洁生产审核、碳排放核查等第三方报告在有效期内 |
| 材料签章齐全 | 所有证明材料有出具单位公章，复印件与原件一致声明齐全 |

## 四、申报书编制
| 检查项 | 通过标准 |
|--------|----------|
| 格式符合模板 | 申报书章节、表格、字数、排版符合当年申报通知模板要求 |
| 指标填列完整 | 评价指标表全部填列，无空项；不适用项说明理由 |
| 数据逻辑一致 | 申报书中不同章节的同一指标数值一致，前后矛盾已修正 |
| 亮点与典型性 | 突出企业/园区的绿色制造特色与创新实践，体现示范价值 |
| 附件清单清晰 | 附件按类别编号整理，目录与实际附件一一对应 |

## 五、现场评价准备
| 检查项 | 通过标准 |
|--------|----------|
| 现场路线规划 | 现场评价参观路线覆盖关键工序、能源设施、环保设施，标识清晰 |
| 资料陈列完整 | 评价期间需查阅的文件、台账、证书按类别整理备索 |
| 人员准备到位 | 各业务口（能源、环保、安全、生产、质量）对接人明确，熟悉相关指标 |
| 整改项闭环 | 前期自评发现的问题已整改或有明确整改计划与时间表 |
| 沟通与反馈机制 | 现场评价意见有专人记录，问题答复有审核把关，避免口头承诺无依据 |
