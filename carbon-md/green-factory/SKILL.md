# Green Factory  绿色工厂/绿色园区申报

## Overview

支持绿色工厂与绿色园区的申报与自评。按绿色制造评价指标体系对照打分，识别差距、补充材料、编制申报书并应对现场评价。核心产出：指标自评 → 差距分析 → 申报材料 → 现场评价准备。

本 Skill 为**数据驱动模式**：零碳工厂培育范围、政策依据、能耗/排放因子一律从 `data/` 数据层动态查询，不在本文件写死行业清单与政策文号；绿色工厂评价指标体系本身数据层暂无专门记录，回退 `references/factory-guide.md` 历史参考并显式标注。

## Workflow

### 1. 明确申报对象、级别、行业与地区
- 确认申报对象（绿色工厂/绿色园区）与级别（国家级/省级/行业/零碳工厂标杆）。
- 确定企业所属行业（如汽车、锂电池、光伏、电子电器、钢铁、建材等）、所在地区与申报报告期。

### 2. 从行业规则表"零碳工厂扩围计划"节点查询培育范围
- 调用 `数据层行业规则表的零碳工厂扩围计划元数据节点`，读取：
  - `2027年培育行业`（汽车、锂电池、光伏、电子电器、轻工、机械、算力设施）；
  - `2030年拓展行业`（钢铁、有色金属、石化化工、建材、纺织）；
  - `依据`（工信部联节〔2026〕13号《关于开展零碳工厂建设工作的指导意见》）。
- 判断企业所在行业当前处于"2027 培育期 / 2030 拓展期 / 暂未纳入零碳工厂培育"，据此确定申报路径与表述口径。
- 注意：零碳工厂培育创建属工信部主导，**并非全国碳市场行业扩围**，二者不可混淆。

### 3. 从政策表查询政策依据（search-policy）
- 执行 `python data/scripts/query_data.py search-policy 零碳工厂` 和 `python data/scripts/query_data.py search-policy 绿色工厂`，获取绿色工厂/零碳工厂相关政策依据，记录文号、发布机关与日期，作为申报材料的政策依据。
- 评价标准（GB/T 36132《绿色工厂评价通则》等）作为核算标准：优先查行业规则表/政策表；**数据层暂无绿色工厂评价标准专门记录**，回退 `references/factory-guide.md` 与 `references/standards-sources.md` 的历史指标体系，并在输出标注"评价标准为 legacy 参考，以当年官方评价通知为准"。

### 4. 执行指标自评脚本（scripts/factory_score.py）
- 用 `scripts/factory_score.py` 汇总评分、识别不达标项；传入 `--industry <行业>` 时脚本自动从数据层判定该行业零碳工厂培育归属并附政策依据。
- 用 `references/factory-guide.md` 对照评价维度逐项自评。
- 能耗与温室气体排放数据衔接 `carbon-accounting`；电力等能耗折算因子从 `query_factor()` 查询（如电力碳足迹因子），数据层查不到时回退 references 并标注 legacy。

### 5. 输出标注（必做）
- 在输出/申报书中标注：**零碳工厂培育范围节点**（2027/2030 行业清单来源）、**政策依据文号与日期**（工信部联节〔2026〕13号，来自政策表）、**评价标准来源**（GB/T 36132 等，注明 legacy 参考 + 当年通知核验）、**因子来源与数据状态**。

## 规范
- 评价指标体系与申报要求以当年官方文件为准，避免用过期标准。
- 自评分须有证明材料支撑，不虚报。
- 能耗与排放数据与核算报告一致（衔接 `carbon-accounting`/`carbon-mrv`）。

### 质量保证与数据规范
- **时效优先原则**：评价指标体系与申报要求以**当年最新官方文件**为准；零碳工厂培育范围与政策依据以 `_data` 数据层查询结果为准（含 `更新日期`），每年评审标准可能调整，使用前务必核实。
- **数据可证原则**：每个自评指标项都有对应的证明材料（证书、报告、台账、票据），不凭空填数。
- **口径一致原则**：能耗、排放、产值等指标在不同申报章节中数值一致，且与企业对外报送的统计 / 环保数据口径一致。
- **指标先进原则**：绿色工厂 / 园区强调行业先进性，关键指标应达到行业先进水平或优于行业平均。
- **闭环改进原则**：自评中发现的差距项有整改计划与时间表，体现持续改进的管理思路。
- 完成申报书编制或自评后，应使用 `references/quality-checklist.md` 逐项自检，通过后方可提交。

### 来源与引用规范
- 引用的评价标准、政策文件、指标先进值均须标注来源（发布机构、文件名、文号、年份）；政策文号与日期优先透传自 `_data` 政策元数据表记录。
- **实测 / 认证数据**（能源计量、体系证书、检测报告）与**自报 / 估算数据**严格区分，自报数据须有计算过程或佐证材料。
- 引用优先级：工信部 / 国家发改委发布的官方文件 > 国家标准（GB/T）> 行业标准 > 行业协会指南 > 第三方咨询报告。
- 行业先进值 / 标杆值应注明发布机构与年份，避免使用过时或来源不明的对标数据。
- 标准与数据来源的详细清单参见 `references/standards-sources.md`。

### 边界与免责
- 本 Skill 提供绿色工厂 / 园区申报的方法论与自评指导，不保证申报一定通过，评审结果以主管部门认定为准。
- 本 Skill 不构成法律、合规或投资建议，申报材料的真实性、合法性由申报主体负责。
- 绿色制造评价标准与申报要求动态更新，每年可能调整指标权重、新增或删减指标，务必以当年最新通知为准。
- 本 Skill 不替代专业申报咨询机构的工作，复杂行业或首次申报建议委托有经验的咨询机构协助。
- 涉及能源审计、清洁生产审核、环境监测等专项工作，应由具备相应资质的机构出具报告。
