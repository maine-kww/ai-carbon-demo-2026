# Climate Adaptation  气候适应与转型金融对接

## Overview

支持企业应对气候变化：评估气候风险（物理/转型）、制定适应与转型策略、对接转型金融工具、进行气候风险披露。核心产出：气候风险评估 → 适应与转型措施 → 转型金融对接 → 披露。面向高碳行业与金融机构，衔接 `carbon-roadmap`、`carbon-esg`。

本 Skill 为**数据驱动模式**：与转型风险直接相关的**碳市场政策**（扩围节点、配额方案、激励政策）从 `data/` 政策元数据表与行业规则表动态查询；但**转型金融/气候适应专项产品标准**（转型债券、可持续挂钩、NGFS 情景等）当前数据层未收录——此时流程设计为"查表 → 未命中则标注数据层未覆盖 + 保留原 references"，绝不编造政策文号。历史值已下沉到 `references/`（并加注"以数据层为准"）。

## 数据层（转型风险/金融对接前必读）

与转型风险直接相关的**碳市场政策**（扩围节点、配额方案、激励政策）从 `data/` 政策元数据表与行业规则表动态查询；但**转型金融/气候适应专项产品标准**（转型债券、可持续挂钩、NGFS 情景等）当前数据层未收录——此时流程设计为"查表 → 未命中则标注数据层未覆盖 + 保留原 references"，绝不编造政策文号。

| 内容 | 数据文件 | 统一查询命令 |
|---|---|---|
| 政策元数据表（气候适应政策、转型金融政策） | `data/policy/policy_metadata.json` | `python data/scripts/query_data.py search-policy <关键词>` |
| 行业规则表（高碳行业转型路径、纳入碳市场状态） | `data/industry/industry_rules.json` | `python data/scripts/query_data.py get-industry <行业名>` |
| 全部行业列表 | `data/industry/industry_rules.json` | `python data/scripts/query_data.py list-industries` |
| 数据版本号 | — | `python data/scripts/query_data.py version` |

> 运行路径：在 `carbon-md/` 根目录下执行上述命令。

数据状态约定：数据层每条记录含 `confidence` 或 `status` 字段。**未覆盖处理原则**：查询转型金融/气候适应专项政策（如关键词"转型金融""可持续挂钩""气候适应""物理风险"）若返回空，须在输出中明确标注"数据层未覆盖"，并以 `references/adaptation-guide.md` 为方法参考。
## Workflow

### 1. 气候风险评估（确定行业/地区）
- 识别**物理风险**（极端天气、海平面、水资源）与**转型风险**（政策、技术、市场、声誉）。
- 用 `references/adaptation-guide.md` 做风险识别与重要性评估；明确主体**所在行业**与地区。

### 2. 从政策元数据表查询转型风险驱动政策
- 执行 `python data/scripts/query_data.py search-policy 行业, 政策类型=配额方案/激励政策/工作方案...)`，获取该行业的碳市场扩围节点、配额清缴要求、零碳工厂等激励政策——这些是转型风险与转型压力的主要政策来源。
- 执行 `python data/scripts/query_data.py search-policy "转型金融"/"可持续挂钩"/"气候适应")` 查询专项产品政策。
- **未命中处理**：若上述专项关键词返回空，显式标注"数据层未覆盖转型金融/气候适应专项政策"，保留 references 作为方法参考，产品条件以金融机构最新条款为准，**不编造文号**。

### 3. 从行业规则表确认转型风险敞口（get-industry）
- 执行 `python data/scripts/query_data.py get-industry <行业名>` 获取该行业纳入碳市场时间、配额方法、是否覆盖间接排放，判断企业碳成本敞口与转型风险强度；行业不在表中时标注"未纳入/未建规则"。

### 4. 制定适应与转型策略、对接转型金融
- 针对物理风险制定适应措施；针对转型风险制定脱碳转型路径（衔接 `carbon-roadmap`，其时间表同样来自数据层政策节点）。
- 用 `scripts/climate_finance.py` 测算挂钩目标与融资要素；传入 `--policy-keyword`/`--industry` 自动附加第 2 步政策查询结果（命中列依据，未命中标注"数据层未覆盖"）。

### 5. 披露与治理
- 按 TCFD/ISSB（衔接 `carbon-esg`）组织气候披露：治理、战略、风险管理、指标目标；披露指标与碳排放/财务/ESG 数据口径一致。
- 建立气候风险治理与监控。

### 6. 输出标注（必做）
- 在输出中标注：**转型政策依据**（来自政策表/行业表，含文号+日期+数据状态）、**未覆盖项**（明确标注"数据层未覆盖 + references 参考"）、气候情景来源（IPCC/NGFS 等）与假设条件。
- 交付：风险评估与策略走 `word`/`lark-doc`，挂钩指标测算走 `sheet`，风险矩阵配合 `doubao-visualization`。

## 规范
- 气候风险情景与数据用权威来源（如 IPCC、TCFD、NGFS），区分事实与假设。
- 转型金融产品以金融机构最新要求为准；涉及真实融资建议专业顾问介入。
- 不夸大适应/转型效果；测算为参考；数据层未命中时不得编造政策依据。

### 质量保证与数据规范
- **情景有据原则**：气候风险评估使用的情景（SSP / NGFS）须来自权威机构，情景假设、时间尺度、温升幅度明确说明。
- **风险透明原则**：物理风险与转型风险的识别、评估方法、关键假设全部公开，区分已知事实与未来预测。
- **转型可信原则**：转型计划应具备科学性、可操作性与雄心度，目标可量化、可验证，避免"漂绿"嫌疑。
- **治理整合原则**：气候风险治理应融入企业现有治理、战略与风险管理体系，不做"两张皮"。
- **披露一致原则**：气候披露指标与企业财务数据、ESG 数据、碳排放数据口径一致，可交叉验证。
- 完成气候风险评估 / 转型方案 / 转型金融方案后，应使用 `references/quality-checklist.md` 逐项自检，通过后方可交付。

### 来源与引用规范
- 气候情景、风险数据、政策文件均需标注来源（机构、报告名、版本、年份）；转型政策引用数据层文号与日期，未覆盖项须明示。
- **历史观测数据**与**模型预测 / 情景数据**严格区分，预测数据注明情景假设与不确定性。
- 引用优先级：IPCC 报告 > TCFD / ISSB 官方指南 > NGFS 情景 > 国际组织（世界银行 / IMF / IEA）报告 > 国家主管部门政策（数据层政策表）> 评级机构方法 > 学术文献。
- 不同行业、不同地区的气候风险差异极大，应针对性选择适用的数据与方法，不做泛化推断。
- 标准与数据来源的详细清单参见 `references/standards-sources.md`（历史参考，以数据层为准；数据层未覆盖部分以本文件为权威方法参考）。

### 边界与免责
- 本 Skill 提供气候风险评估、适应策略与转型金融的方法论指导，不构成投资、融资或法律建议。
- 本 Skill 不对气候情景预测的准确性做保证，气候系统存在内在不确定性，历史数据不代表未来。
- 本 Skill 不替代专业的气候风险建模机构、第三方验证机构或金融法律顾问的服务。
- 转型金融产品标准、监管要求、市场实践处于快速发展中（数据层当前未覆盖专项政策），实际对接应以金融机构与监管机构的最新要求为准。
- 气候披露涉及重大信息公开责任，企业应根据自身情况审慎披露，必要时由专业机构鉴证。
