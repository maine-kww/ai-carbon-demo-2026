# 气候适应与转型金融对接质量检查清单

> **历史参考，以 _data 数据层为准（2026-10-09）**：本文件涉及的核算/披露标准版本、排放因子、配额分配与激励政策等参数，正式使用时一律从 `_data` 数据层（`query.py` 的 query_industry / query_factor / query_policy）动态查询；本文件仅作数据层未命中时的 legacy 回退与背景参考，回退使用时须在输出中标注“legacy 回退”。

## 一、气候风险评估
| 检查项 | 通过标准 |
|--------|----------|
| 物理风险识别全面 | 急性风险（极端高温、暴雨洪涝、飓风、干旱、野火）与慢性风险（海平面上升、温度升高、水资源变化）均覆盖 |
| 转型风险分类清晰 | 政策法规、技术、市场、声誉四类转型风险全部识别，结合行业特点具体化 |
| 风险传导路径清晰 | 从气候驱动因素 → 风险事件 → 对企业财务 / 运营的影响，传导链条分析到位 |
| 情景选择合理 | 至少采用 IPCC 典型情景（如 SSP1-2.6 / SSP2-4.5 / SSP5-8.5）或 NGFS 情景，短中长时间尺度明确 |
| 风险量化 / 定性区分 | 能量化的财务影响尽量量化，难以量化的做定性分级（高 / 中 / 低），不夸大也不回避 |

## 二、适应与转型策略
| 检查项 | 通过标准 |
|--------|----------|
| 适应措施可落地 | 物理风险适应措施（防洪排涝、降温改造、水资源管理、供应链韧性等）有具体方案与时间表 |
| 转型路径科学 | 高碳资产的转型路径（技术替代、产能退出、业务转型）与行业趋势、政策方向一致 |
| 目标设定可测 | 气候韧性目标与转型目标量化、可监测，有明确的指标与里程碑 |
| 投资与成本测算 | 适应与转型措施的投资估算、运营成本、预期效益（减损 / 增值）有测算 |
| 公正转型考量 | 转型中员工安置、社区影响等社会维度有考虑，体现"公正转型"理念 |

## 三、转型金融对接
| 检查项 | 通过标准 |
|--------|----------|
| 产品类型匹配 | 转型债券 / 可持续挂钩债券（SLB）/ 可持续发展挂钩贷款（SLL）等产品选择与企业转型路径匹配 |
| 转型计划可信 | 转型计划（含目标、路径、时间表）符合发行 / 贷款机构对"可信转型"的要求 |
| KPI 选择合理 | 可持续发展绩效指标（SPT / KPI）与核心业务相关、可量化、可第三方验证 |
| 目标设定有雄心 | 绩效目标具有挑战性，优于历史表现与行业平均，符合 1.5℃ 路径（如适用） |
| 资金用途透明 | 绿色债券 / 转型债券的募集资金用途明确，全部用于合格项目，且有跟踪与披露机制 |

## 四、治理与披露
| 检查项 | 通过标准 |
|--------|----------|
| 治理架构到位 | 董事会对气候风险的监督职责、管理层执行职责明确，纳入公司治理体系 |
| 战略整合充分 | 气候风险与机遇已纳入企业战略规划、投资决策、风险管理框架 |
| 风险管理融入 | 气候风险识别、评估、应对、监控流程与企业现有风险管理体系融合 |
| 披露符合 TCFD / ISSB 框架 | 治理、战略、风险管理、指标与目标四大支柱披露齐全，符合 TCFD / ISSB 要求 |
| 数据与指标一致 | 气候相关指标与财务、ESG 数据口径一致，范围 1/2/3 排放数据完整（如适用） |

## 五、合规与边界
| 检查项 | 通过标准 |
|--------|----------|
| 不漂绿承诺 | 转型目标真实可行，披露信息真实准确，不做虚假或误导性声明 |
| 第三方验证安排 | 气候数据、KPI 绩效、转型进展等关键信息有第三方验证安排或计划 |
| 信息更新机制 | 气候风险评估、转型计划、目标进展定期更新（至少每年一次），重大变化及时披露 |
| 法律合规审查 | 转型金融产品发行 / 贷款涉及的法律文件、信息披露义务已做合规审查 |
