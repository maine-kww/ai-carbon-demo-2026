# 碳金融产品对接标准与来源索引

> **历史参考，以 _data 数据层为准（2026-10-09）**：本文件涉及的核算/披露标准版本、排放因子、配额分配与激励政策等参数，正式使用时一律从 `_data` 数据层（`query.py` 的 query_industry / query_factor / query_policy）动态查询；本文件仅作数据层未命中时的 legacy 回退与背景参考，回退使用时须在输出中标注“legacy 回退”。

## 一、核心标准与法规

| 序号 | 标准/法规名称 | 发布机构 | 年份 | 用途说明 |
|------|--------------|----------|------|----------|
| 1 | 碳排放权交易管理办法（试行） | 生态环境部 | 2020 | 全国碳市场顶层制度，碳配额的法律属性与交易规则的基础 |
| 2 | 关于推动绿色金融发展的指导意见 / 绿色金融改革创新 | 人民银行 / 银保监会 / 证监会 | 2016-2024 | 中国绿色金融体系顶层设计，碳金融产品的政策依据 |
| 3 | 碳排放权登记管理规则 / 交易管理规则 / 结算管理规则 | 生态环境部 | 2021 | 全国碳市场登记、交易、结算三大核心规则 |
| 4 | 绿色金融标准（绿色贷款 / 绿色债券 / 碳金融产品标准） | 人民银行 / 全国金融标准化技术委员会 | 2020-2024 | 绿色金融产品分类、统计、信息披露的标准规范 |
| 5 | 碳减排支持工具 / 支持煤炭清洁高效利用专项再贷款 | 人民银行 | 2021-2024 | 央行结构性货币政策工具，为减排项目提供低成本资金 |
| 6 | 上海市 / 广东省等地方碳金融试点政策 | 地方金融监管局 / 地方生态环境局 | 2014-2024 | 地方碳市场碳质押、碳回购、碳远期等创新产品的政策依据 |
| 7 | ISO 14030 绿色金融 — 环境风险与机遇识别 | ISO | 2023+ | 国际绿色金融与环境风险的标准参考 |

| 序号 | 数据来源 | 提供机构 | 用途说明 |

| 5 | 国际碳价（EU ETS / CCA 等） | EEX / ICE / 各交易所 | 国际主要碳市场价格参考，用于趋势判断与对标 |
