# 碳金融产品对接质量检查清单

> **历史参考，以 _data 数据层为准（2026-10-09）**：本文件涉及的核算/披露标准版本、排放因子、配额分配与激励政策等参数，正式使用时一律从 `_data` 数据层（`query.py` 的 query_industry / query_factor / query_policy）动态查询；本文件仅作数据层未命中时的 legacy 回退与背景参考，回退使用时须在输出中标注“legacy 回退”。

## 一、碳资产确权与合规
| 检查项 | 通过标准 |
|--------|----------|
| 碳资产权属清晰 | 碳配额 / CCER 登记在企业名下，登记系统可查，无权属争议 |
| 资产状态正常 | 碳资产未被冻结、质押、查封或处于争议状态，可正常处置 |
| 配额清缴义务明晰 | 配额资产对应年度的履约义务已明确，不影响正常清缴 |
| 企业资质合规 | 借款方 / 出质方为合法存续企业主体，符合金融机构准入条件 |
| 交易场所合规 | 在经批准的碳交易场所（全国碳市场 / 地方试点）进行，不参与场外非法交易 |

## 二、产品选择与需求匹配
| 检查项 | 通过标准 |
|--------|----------|
| 融资目的明确 | 流动性补充 / 价格风险管理 / 资产盘活 / 绿色转型融资等需求清晰 |
| 产品类型匹配 | 所选产品（质押 / 回购 / 远期 / 基金）与融资目的、期限、风险承受能力匹配 |
| 期限结构合理 | 融资期限与企业现金流、配额清缴周期匹配，避免期限错配 |
| 成本收益测算完整 | 利息 / 费率 / 保证金 / 交易成本 / 机会成本等全部纳入测算 |

## 三、额度与价值测算
| 检查项 | 通过标准 |
|--------|----------|
| 碳资产估值有据 | 碳资产价值基于市场成交价 / 近期均价 / 行业基准，估值方法与参数明确 |
| 质押率 / 杠杆率合理 | 质押率、保证金比例符合金融机构规定与市场惯例，不过度杠杆 |
| 价格风险覆盖 | 测算中考虑碳价波动风险，设置预警线 / 平仓线 / 追加保证金机制 |
| 情景分析完整 | 至少包含基准、乐观、悲观三种情景下的融资成本与风险测算 |
| 测算公式透明 | 额度、利息、费用、收益等计算过程公开可复核，无隐藏条款 |

## 四、风险识别与管控
| 检查项 | 通过标准 |
|--------|----------|
| 价格风险评估 | 碳价波动历史、波动率、影响因素（政策、供需、宏观）有分析与应对预案 |
| 流动性风险评估 | 碳资产变现能力、市场深度、交易量等流动性指标有评估 |
| 政策风险评估 | 碳市场政策变化（配额分配方法、抵消比例）对资产价值的影响有预判 |
| 法律合规风险 | 质押登记、合同效力、违约处置、税务处理等法律问题已评估 |
| 操作风险控制 | 交易账户安全、划转流程、指令审核等操作风险有管控措施 |

## 五、文件与流程
| 检查项 | 通过标准 |
|--------|----------|
| 合同文本完整 | 主合同（质押 / 回购 / 远期协议）与从合同（保证 / 抵押）文本齐全 |
| 登记 / 备案到位 | 质押登记、交易备案等法定 / 约定程序履行完毕 |
| 信息披露充分 | 向金融机构 / 投资方如实披露企业经营、碳资产、风险等重要信息 |
| 贷后 / 持仓管理 | 建立贷后 / 持仓期间的碳价监控、追加保证金、风险处置等流程 |
