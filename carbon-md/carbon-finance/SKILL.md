# Carbon Finance  碳金融产品对接（碳质押/回购/远期/基金）

## Overview

支持企业将碳资产（配额/CCER）对接碳金融产品，实现融资与资产盘活。核心：识别产品类型 → 评估碳资产价值 → 测算融资额度与成本 → 对接金融机构 → 风险提示。碳金融衔接 `carbon-trading` 的资产与行情，面向金融客户与控排企业刚需。

本 Skill 为**数据驱动模式**：碳资产背后的**配额方案、激励政策、CCER 规章**等政策依据一律从 `data/` 政策元数据表动态查询，不在本文件写死政策文号；质押率/碳价等市场参数以实际机构与行情为准（数据层未收录，属 legacy 经验缺省，须标注）。历史值已下沉到 `references/`（并加注"以数据层为准"）。

## 数据层（融资测算前必读）

碳资产背后的**配额方案、激励政策、CCER 规章**等政策依据一律从 `data/` 数据层动态查询，**不在本文件写死政策文号**。质押率/碳价等市场参数以实际机构与行情为准（数据层未收录）。

| 内容 | 数据文件 | 统一查询命令 |
|---|---|---|
| 行业规则表（控排行业、配额量估算、纳入状态） | `data/industry/industry_rules.json` | `python data/scripts/query_data.py get-industry <行业名>` |
| 政策元数据表（碳金融政策、配额方案、CCER规章） | `data/policy/policy_metadata.json` | `python data/scripts/query_data.py search-policy <关键词>` |
| 数据版本号 | — | `python data/scripts/query_data.py version` |

> 运行路径：在 `carbon-md/` 根目录下执行上述命令。

数据状态约定：数据层每条记录含 `confidence` 或 `status` 字段，引用时透传文号、发布日期与数据状态。碳价、利率、质押率等市场参数**数据层不收录**，须取实时行情/机构条款并标注来源与日期。
## Workflow

### 1. 明确需求与碳资产
- 确认融资/交易需求（盘活配额、补充流动性、锁定价格）。
- 明确可质押/可交易碳资产（配额、CCER）数量与价值，参考 `carbon-trading` 测算；确定碳资产所属**行业**。

### 2. 选择产品类型
- 读取 `references/finance-guide.md` 对比碳质押、回购、远期、基金等产品特点与适用场景。

### 3. 从政策元数据表查询碳资产政策依据（search-policy，本 Skill 重点）
- 执行 `python data/scripts/query_data.py search-policy ..., 政策类型=配额方案)` 查询该行业配额分配/清缴方案（如国环规气候〔2025〕2号、〔2026〕1号），判断配额确权与清缴节点对质押的约束。
- 执行 `python data/scripts/query_data.py search-policy 政策类型=激励政策)` 查询零碳工厂等激励政策（工信部联节〔2026〕13号），识别可对接的绿色/转型融资场景。
- 执行 `python data/scripts/query_data.py search-policy CCER)` 获取《温室气体自愿减排交易管理办法（试行）》（生态环境部令第31号）作为 CCER 资产合规依据。
- 记录文号、发布日期、时效状态、数据状态；未命中不得编造，改用 references 并标注"待核"。

### 4. 测算额度与成本
- 使用 `scripts/carbon_finance.py` 测算质押融资额度（碳资产价值×质押率）、回购/远期测算；传入 `--industry` 自动附加第 3 步查询到的政策依据标注。
- 质押率默认 0.6 为审慎经验缺省值（legacy，非数据层数值），实际须以具体金融机构/交易所最新规定为准；结合碳价行情（参考 `carbon-trading`）与利率/费率。

### 5. 对接金融机构与风险提示
- 梳理对接对象：银行、交易所平台、碳资产管理机构；准备材料：碳资产证明、核算报告、企业信息。
- 按 `references/finance-guide.md` 提示价格波动、违约、合规与确权风险。
- 交付：测算表走 `sheet`，方案说明走 `lark-doc`/`word`。

### 6. 输出标注（必做）
- 在输出中标注：**碳价/利率/质押率来源与日期**（机构+发布日期，市场参数非数据层）、**配额/激励/CCER 政策依据**（文号+发布日期+数据状态，来自政策表）、数据状态（已查证/估算/占位-待核实/legacy 经验值/待核）。

## 规范
- 碳金融产品规则与质押率随市场与机构政策变化，以具体金融机构/交易所最新规定为准；政策文号以数据层查询结果为准。
- 测算为参考，不构成投资/融资建议；重大融资决策建议金融与法律顾问介入。
- 涉及真实资金，确认合规与碳资产确权。

### 质量保证与数据规范
- **资产确权原则**：碳金融业务的前提是碳资产权属清晰、状态正常，未被冻结或质押，避免无权处分风险。
- **风险匹配原则**：产品选择与企业风险承受能力匹配，高杠杆 / 高波动产品需谨慎评估。
- **估值审慎原则**：碳资产估值采用保守参数（如 90 日均价或历史低位），避免基于短期高价高估资产价值。
- **成本透明原则**：融资成本应包含利息、手续费、交易费、登记费等全部费用，不得以单一利率误导。
- **合规优先原则**：所有产品与操作须在合规交易场所与监管框架内进行，政策依据以数据层政策表为准，不参与场外非法金融活动。
- 完成碳金融方案或测算后，应使用 `references/quality-checklist.md` 逐项自检，通过后方可交付。

### 来源与引用规范
- 碳价、利率、费率、质押率等数据均需标注来源（交易所、金融机构、发布日期）；政策依据引用数据层文号与日期。
- **市场公开数据**与**估算 / 预测值**严格区分，预测值注明假设条件与不确定性。
- 引用优先级：官方交易所行情 > 金融机构公布的产品条款 > 人民银行 / 金融监管政策文件（数据层政策表）> 行业研究报告 > 媒体报道。
- 不同试点市场、不同金融机构的产品规则差异较大，应明确适用的市场与机构，不通用化表述。
- 标准与数据来源的详细清单参见 `references/standards-sources.md`（历史参考，以数据层为准）。

### 边界与免责
- 本 Skill 提供碳金融产品的方法论介绍与测算参考，**不构成任何投资、融资、理财建议**。
- 本 Skill 不对碳金融产品的收益或风险做任何保证，实际业务以金融机构的正式合同为准。
- 碳价受政策、供需、宏观经济等多重因素影响，波动较大，历史价格不代表未来走势。
- 本 Skill 不替代专业的金融顾问、法律顾问或税务顾问服务；涉及真实资金操作，应咨询专业机构。
- 碳金融监管政策处于快速发展中，相关规则可能随时间调整，操作前应核实最新监管要求（以数据层更新为准）。
