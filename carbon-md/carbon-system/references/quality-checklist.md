# 企业碳管理体系建设质量检查清单

> **历史参考，以 _data 数据层为准（2026-10-09）**：本文件涉及的核算/披露标准版本、排放因子、配额分配与激励政策等参数，正式使用时一律从 `_data` 数据层（`query.py` 的 query_industry / query_factor / query_policy）动态查询；本文件仅作数据层未命中时的 legacy 回退与背景参考，回退使用时须在输出中标注“legacy 回退”。

## 一、领导与治理
| 检查项 | 通过标准 |
|--------|----------|
| 最高管理者承诺 | 最高管理层（董事长 / 总经理）对碳管理工作有正式承诺（如发布碳达峰碳中和宣言） |
| 治理架构清晰 | 设立碳管理委员会 / 领导小组，决策、执行、监督三层职责明确 |
| 资源配置到位 | 碳管理所需的人力（专职 / 兼职岗位）、预算、信息化工具有明确安排 |
| 碳方针正式发布 | 企业碳管理方针 / 政策正式发布，内容涵盖目标承诺、合规义务、持续改进 |
| 职责横向到边 | 生产、能源、采购、财务、ESG、法务等各相关部门碳职责明确，无责任真空 |

## 二、目标与指标
| 检查项 | 通过标准 |
|--------|----------|
| 目标体系完整 | 总体目标（达峰 / 中和 / 减排率）+ 年度分解目标 + 重点任务指标，层层分解 |
| 目标可测量 | 目标量化、可考核，有明确的统计口径与计算方法 |
| 目标分解落地 | 目标分解到部门 / 车间 / 重点排放源，责任主体明确 |
| 绩效考核挂钩 | 碳目标纳入相关部门与岗位绩效考核，有激励约束机制 |

## 三、制度与流程
| 检查项 | 通过标准 |
|--------|----------|
| 体系文件层级清晰 | 管理手册 → 程序文件 → 作业指导书 / 记录表格，三级文件结构完整 |
| 核心流程完备 | 碳核算流程、数据管理流程、目标管理流程、报告与披露流程、合规管理流程等关键流程有文件 |
| 文件控制规范 | 文件有编号、版本、发布 / 修订记录，分发与作废管理规范 |
| 记录可追溯 | 排放数据、会议纪要、培训记录、评审记录等有保存期限要求且实际执行 |
| 与现有体系协同 | 与 ISO 9001 / ISO 14001 / ISO 50001 等既有管理体系有机融合，不搞"两张皮" |

## 四、数据与监测
| 检查项 | 通过标准 |
|--------|----------|
| 排放源清单完整 | 企业范围 1 / 2 / 3 排放源清单建立并动态更新 |
| 数据质量有保障 | 数据采集、录入、审核、异常处理、缺失补全的质量控制流程明确（衔接 MRV 体系） |
| 计量器具管理 | 重点排放源计量器具清单、校准计划、检定证书齐备 |
| 信息化支撑 | 碳管理信息系统 / 数据台账工具可用，减少人工统计误差 |

## 五、运行与持续改进
| 检查项 | 通过标准 |
|--------|----------|
| 内部审核机制 | 定期开展碳管理体系内部审核，发现问题有整改与跟踪验证 |
| 管理评审机制 | 最高管理层定期（至少每年一次）评审体系适宜性、充分性、有效性 |
| 培训与能力建设 | 碳管理相关岗位人员有培训计划与实施记录，能力满足岗位要求 |
| 合规义务管理 | 碳相关法律法规、政策标准清单建立并动态更新，合规性定期评价 |
| 持续改进闭环 | 审核、评审、合规评价中发现的问题有纠正措施与预防措施，形成 PDCA 闭环 |
