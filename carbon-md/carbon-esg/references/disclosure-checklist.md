# ESG 报告质量检查清单

> **历史参考，以 _data 数据层为准（2026-10-09）**：本文件涉及的核算/披露标准版本、排放因子、配额分配与激励政策等参数，正式使用时一律从 `_data` 数据层（`query.py` 的 query_industry / query_factor / query_policy）动态查询；本文件仅作数据层未命中时的 legacy 回退与背景参考，回退使用时须在输出中标注“legacy 回退”。

> 报告编制完成后逐项检查，确保内容完整、数据可靠、披露规范。

## 一、框架符合性

- [ ] **主披露框架已确定**：GRI / ISSB / TCFD / 监管指引 / 组合使用
- [ ] **框架版本已注明**：具体年份和版本号，如 GRI 2021、ISSB 2023
- [ ] **强制披露项全部覆盖**：对照所选框架的强制要求逐项核对
- [ ] **"不披露就解释"项有解释**：未披露的"建议披露"项给出了合理理由
- [ ] **报告范围与边界明确**：组织边界、报告期、数据覆盖范围已说明

## 二、数据质量

- [ ] **每项指标有数据来源**：财务系统 / HR 系统 / 运营系统 / 第三方报告 / 估算
- [ ] **口径定义清晰**：每个指标都有计算方法和边界说明
- [ ] **估算项已标注**：所有估算数据显式标记（估算），并说明方法
- [ ] **关键指标可核验**：营收、员工、排放等核心数据有对应支撑材料
- [ ] **排放数据与碳核算一致**：ESG 报告中的排放数据 = carbon-accounting 的核算结果
- [ ] **跨期数据可比**：口径变更已说明，必要时重述了基期数据
- [ ] **单位统一**：同类指标使用相同单位，不出现混用

## 三、内容完整性（E/S/G 三支柱）

### 环境（E）
- [ ] 温室气体排放（范围 1/2/3，至少范围 1+2）
- [ ] 能源消耗总量与结构（可再生能源占比）
- [ ] 水资源管理（取水量、消耗量、回用率）
- [ ] 废弃物管理（产生量、处置方式、回收率）
- [ ] 污染排放（废水、废气、固废，如有）
- [ ] 气候相关风险与机遇（TCFD/ISSB 要求）
- [ ] 环境目标与减排路径

### 社会（S）
- [ ] 员工情况（人数、结构、流动率）
- [ ] 职业健康与安全（工伤率、安全培训）
- [ ] 薪酬与福利（性别薪酬差距，如有）
- [ ] 培训与发展（培训小时数、覆盖率）
- [ ] 多元化与包容性（性别、年龄、背景等）
- [ ] 供应链管理（供应商准入、社会责任）
- [ ] 社区投入与公益

### 治理（G）
- [ ] 董事会结构与独立性
- [ ] 董事会对 ESG 议题的监督
- [ ] 风险管理体系（ESG 风险识别与管控）
- [ ] 合规与反腐败
- [ ] 信息披露机制（披露渠道、频率）
- [ ] 商业道德与行为准则

## 四、气候专项披露（TCFD/ISSB S2）

- [ ] **治理**：董事会如何监督气候相关风险
- [ ] **战略**：气候风险与机遇对业务模式和战略的影响
- [ ] **风险管理**：气候风险的识别、评估和管理流程
- [ ] **指标与目标**：
  - [ ] 范围 1、2、3 排放量
  - [ ] 情景分析（如有）
  - [ ] 减排目标（含时间线和基线）
  - [ ] 气候相关财务影响（如有）

## 五、绿色金融专项（绿色信贷/绿色债券）

- [ ] **项目符合绿色目录**：具体到目录条款编号
- [ ] **募集资金用途清晰**：具体投向、金额、占比
- [ ] **资金管理规范**：专项台账、专款专用
- [ ] **环境效益可量化**：减排量、节能量等，有测算方法
- [ ] **披露机制完善**：定期披露项目进展和环境效益
- [ ] **认定标准已注明**：目录名称、版本、发布机构

## 六、常见问题检查

- [ ] 数据前后矛盾（同一指标在不同章节数值不一致）
- [ ] 只有口号没有数据（"我们重视环保"但没有任何环境指标）
- [ ] 指标口径含糊（"减少碳排放"但不说减了多少、从哪年的基线减）
- [ ] 只报好不报坏（全是正面成绩，没有风险和挑战）
- [ ] 第三方核查标注不清（说了"经核查"但不说是谁核的、核了什么）
- [ ] 与上期数据对不上又没有解释
- [ ] 绿色洗白嫌疑（Greenwashing）：声称的绿色效益与实际投入不成比例

## 七、发布前检查

- [ ] 所有声明和数据都有支撑材料
- [ ] 没有未核实的夸大数据
- [ ] 免责声明已包含（不构成审计/法律意见）
- [ ] 如涉及合规申报，已由专业机构或律师复核
- [ ] 报告语言符合目标读者（投资者/监管/公众）

> 💡 **建议**：正式发布前，找一个不参与编制的人通读一遍，从读者视角检查"读得懂、信得过、用得上"吗。
