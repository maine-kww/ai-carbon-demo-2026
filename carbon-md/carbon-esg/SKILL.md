# Carbon Esg  ESG 与绿色金融披露

## Overview

支持 ESG 报告编制、绿色金融认定与气候相关披露。将企业环境、社会、治理信息组织为符合主流框架的报告与认定材料。核心产出：披露框架选择 → 指标与数据口径 → 报告/认定材料。

本 Skill 为**数据驱动模式**：披露与核算所依据的**标准版本、监管政策、行业核算规则、排放因子**一律从 `data/` 数据层动态查询，不在本文件写死标准编号/年份/政策文号；历史值已下沉到 `references/`（并加注"以数据层为准"）。

## 数据层（披露编制前必读）

所有行业规则、政策依据、排放因子均从 `data/` 数据层动态查询，**不在本 Skill 中写死任何标准编号/年份/政策文号**。新增行业或政策更新只需在数据层追加记录，无需修改本 Skill 代码。

| 内容 | 数据文件 | 统一查询命令 |
|---|---|---|
| 政策元数据表（披露/监管/核算政策与文号日期） | `data/policy/policy_metadata.json` | `python data/scripts/query_data.py search-policy <关键词>` |
| 行业规则表（行业核算标准、纳入碳市场状态） | `data/industry/industry_rules.json` | `python data/scripts/query_data.py get-industry <行业名>` |
| 电网排放因子库 | `data/factors/grid_electricity_factors.json` | `python data/scripts/query_data.py get-grid-factor --year <年份> --region <区域>` |
| 化石燃料因子库 | `data/factors/fossil_fuel_factors.json` | `python data/scripts/query_data.py get-fuel-factor <燃料类型>` |
| 工业过程因子库 | `data/factors/industrial_process_factors.json` | `python data/scripts/query_data.py get-process-factor <行业名>` |
| 数据版本号 | — | `python data/scripts/query_data.py version` |

> 运行路径：在 `carbon-md/` 根目录下执行上述命令。

数据状态约定：数据层每条记录含 `confidence` 或 `status` 字段，输出时必须透传，不得把估算/占位当已查证输出。GRI/SASB/ISSB/TCFD 等国际披露框架本身数据层未收录，仍以 `references/frameworks.md` 为背景参考，并标注其版本以官方最新发布为准。

## Workflow

### 1. 明确披露目标、对象与报告期（数据驱动起点）
- 确认用途：ESG 报告、绿色信贷/债券认定、气候信息披露、监管披露（如港交所、上市公司要求），还是投资机构问卷。
- 确认主体类型（上市公司/拟上市/中小企业/项目主体）、**所在行业**、报告期年份与所在地区。

### 2. 从政策元数据表查询披露/核算政策与标准版本（search-policy，本 skill 主入口）
- 执行 `python data/scripts/query_data.py search-policy <关键词>`（如：ESG、绿色金融、披露、核算指南 等），从政策元数据表获取适用于该行业/地区的：
  - 核算与披露标准（如 GB/T 32150-2025 通则、各行业 GB/T 32151 分册、行业核算报告指南文号）；
  - 配额/履约类政策（影响"合规"维度披露）；
  - 排放因子发布公告（影响环境指标口径与年份）。
- 记录命中政策的**政策名称、文号、发文机关、发布日期、时效状态、数据状态**，作为披露的政策依据；未命中时不得自行编造文号，改用 `references/standards-index.md` 历史索引并标注"待核"。

### 3. 从行业规则表查询行业核算规则（get-industry）
- 执行 `python data/scripts/query_data.py get-industry <行业名>`，获取该行业核算标准（GB/T 编号及版本）、纳入碳市场状态、是否覆盖间接排放、核查要求。
- 行业不在表中：提示"该行业规则未建立/未纳入碳市场"，披露相关内容采用通用口径并标注。

### 4. 从排放因子库查询环境指标因子
- 环境指标（排放/能耗/电力折算）按 行业/年份/能源类型/地区 根据因子类别选择相应命令（get-fuel-factor / get-grid-factor / get-process-factor）；多条命中优先"已查证"。
- 数据层查不到时回退 `references/` 历史参考值并标注"legacy 回退"；正式排放数据统一引用 `carbon-accounting` 核算结果，保持口径一致。

### 5. 编制报告或认定材料
- 披露框架选择：读取 `references/frameworks.md` 对照 GRI、SASB、ISSB（IFRS S1/S2）、TCFD、中国证监会/交易所 ESG 指引的适用范围。
- 指标与口径：用 `references/indicators.md` 确定核心指标（环境/社会/治理），数据来源与口径按第 2–4 步查询结果填写。
- 绿色金融：用 `references/green-finance.md` 核对绿色信贷/债券项目的绿色目录符合性、资金用途与披露要求。
- 交付：正式报告走 `word`，数据表走 `sheet`，结构/指标可视化配合 `doubao-visualization`。

### 6. 输出标注（必做）
- 在输出中标注：**披露框架版本**（发布方+版本/年份）、**核算/披露标准版本**（来自政策表/行业表）、**排放因子来源**（机构+年份+数据状态）、**政策依据的文号与日期**（来自政策元数据表）、数据状态（已查证/估算/占位-待核实/legacy 回退/待核）。

## 质量保证与数据规范

### 数据质量控制
- **可追溯性**：每项指标须注明定义、边界、单位、计算期间、数据来源；无来源数据不得进入正式报告。
- **口径一致性**：跨期对比须注明口径变化，必要时重述基期数据，避免"看起来增减"实则是口径变了。
- **估算管理**：估算项显式标注（估算），并说明估算方法和依据；C 级（估算/经验值）数据占比超过 10% 时须说明影响。
- **排放数据统一**：环境指标（尤其是排放数据）引用 `carbon-accounting` 的核算结果，保持口径一致，不得两套数据。

### 披露质量要求
- **合规底线**：以监管强制要求为底线（依据来自政策元数据表），自愿框架为加分项，不为了"好看"堆砌无关指标。
- **不披露就解释**：未披露的建议项必须给出合理解释（如数据获取成本过高、不适用本行业），不能沉默跳过。
- **绿色认定严谨**：绿色金融认定依据最新绿色目录与监管要求，注明认定标准版本、发布日期和具体条款编号。
- **气候披露完整**：ISSB / TCFD 气候披露须覆盖四大支柱（治理、战略、风险管理、指标与目标），缺一不可。

### 自检流程
- 报告编制完成后，须按 `references/quality-checklist.md` 逐项自检（披露完整性/数据质量/合规性/一致性/可比性五维度）。
- 框架符合性与内容完整性检查走 `references/disclosure-checklist.md`。
- 关键指标建议抽样反向追溯，验证数据来源→计算过程→报告数值的完整闭环。

## 来源与引用规范

### 引用优先级
1. **监管强制要求**：证监会/交易所公告、正式法律法规、港交所上市规则（政策元数据表优先）
2. **主流披露框架**：GRI、ISSB（IFRS S1/S2）、TCFD
3. **国家标准与行业指南**：GB/T 系列、行业核算报告指南（政策元数据表/行业规则表）
4. **行业协会与第三方标准**：SASB、CDP、绿色目录等

### 事实与假设区分
- **事实陈述**：政策原文条款、已发布的标准要求、企业已发生的数据 → 直接陈述，标注来源
- **判断/建议**：对影响的分析、改进建议、趋势预判 → 明确标注"分析认为"或"建议"，与事实分开
- **假设与估算**：基于假设的测算、情景分析结果 → 必须注明假设条件和估算方法，不得当作确定事实呈现

### 引用标注要求
- **披露框架**：发布方 + 文件全名 + 版本/年份，如 `GRI 2021 标准（GRI Universal Standards 2021）`
- **监管文件**：发文机构 + 文号 + 标题，优先取政策元数据表记录（如《上市公司投资者关系管理指引》），文号/日期未命中时标"待核"
- **绿色目录**：发布机构 + 目录名称 + 版本 + 具体条款，如《绿色债券支持项目目录（2021 年版）》第 1.1 项"节能"类
- **ESG 评级/数据**：必须说明评级机构、方法学版本和数据年份，不得只说"ESG 评级为 A"

完整的标准出处与引用格式见 `references/standards-sources.md`（历史参考，以数据层为准）。

## 边界与免责

- 本 Skill 提供 ESG 报告编制与绿色金融认定支持，**不构成审计意见、法律意见或正式鉴证结论**。
- 对外披露的正式报告建议由具备资质的第三方机构核验或审计。
- 绿色金融认定仅作内部参考，最终以监管部门或金融机构的正式认定为准。
- ESG 评级与对标数据仅作参考，不同评级机构方法学差异大，不代表对企业价值的判断。
- 不提供投资建议，不对披露后的市场反应或监管处罚承担责任。
