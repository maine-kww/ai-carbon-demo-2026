# 碳汇项目开发质量检查清单

> 历史参考，以 _data 数据层为准（2026-10-09）：清单涉及的 CCER 制度依据（部令第31号）与政策文号以 `_data` 政策元数据表查询结果为准；本清单为交付前自检框架。

## 一、项目边界与方法学选择
| 检查项 | 通过标准 |
|--------|----------|
| 碳汇类型识别正确 | 林业（造林/再造林/森林经营）、海洋蓝碳（红树林/海草床/盐沼）、草地等分类准确 |
| 方法学适用性匹配 | 所选方法学（CCER / 省级碳汇 / 国际机制）与项目类型、区域、林分/植被状况完全匹配 |
| 地理边界清晰可核实 | 项目地块四至范围、面积、坐标（经纬度）明确，可通过 GIS 或卫星影像核实 |
| 碳库选择完整 | 按方法学要求纳入地上生物量、地下生物量、枯落物、枯死木、土壤有机碳等碳库 |
| 计入期合理 | 计入期长度与起始年符合方法学规定（林业一般 20-30 年），与土地使用期限匹配 |

## 二、基线与碳汇量核算
| 检查项 | 通过标准 |
|--------|----------|
| 基线情景设定有据 | 基线情景（无项目时的碳库变化趋势）有实测数据或方法学默认值支撑 |
| 碳储量计算方法正确 | 使用方法学规定的生物量模型 / 蓄积量扩展因子 / 土壤碳密度法，公式与参数选择合规 |
| 泄漏评估到位 | 评估项目活动导致的排放转移（如采伐转移、放牧转移），计入或排除有依据 |
| 项目排放识别完整 | 项目活动产生的化石燃料消耗、运输、化肥农药使用等排放全部纳入 |
| 碳汇量公式正确 | 净碳汇量 = Δ项目碳库 − Δ基线碳库 − 项目排放 − 泄漏，不遗漏项 |

## 三、数据质量与监测
| 检查项 | 通过标准 |
|--------|----------|
| 样地设计符合规范 | 样地数量、布局、面积满足方法学与监测技术规程要求，有统计学代表性 |
| 基础参数来源权威 | 生物量扩展因子（BEF）、根冠比（R）、含碳率（CF）、木材密度等参数来自官方或权威文献 |
| 土壤碳数据可靠 | 土壤有机碳测定方法（干烧法 / 重铬酸钾法）符合标准，采样深度与重复数符合要求 |
| 遥感/样地数据对应 | 遥感反演数据有地面样地校准，精度评估结果满足方法学要求 |
| 长期监测计划完善 | 监测频率、内容、责任方、数据保存与质量控制流程明确，覆盖整个计入期 |

## 四、土地与合规
| 检查项 | 通过标准 |
|--------|----------|
| 土地权属清晰 | 林地/海域/草地使用权属证明完整，无争议，使用期限覆盖计入期 |
| 土地利用历史合规 | 项目开始前土地利用状况符合方法学要求（如造林地需符合无林地定义） |
| 非碳效益评估 | 生物多样性保护、社区发展、水资源等方面的影响已评估并采取措施 |
| 利益相关方协商 | 当地社区、原住民（如涉及）咨询程序完成，意见有记录与回应 |

## 五、文档与风险
| 检查项 | 通过标准 |
|--------|----------|
| PDD / 项目文件完整 | 设计文件含项目描述、基线方法、监测计划、额外性论证、环境社会影响等全部章节 |
| 自然风险评估 | 火灾、病虫害、极端气候、人为干扰等逆转风险已评估，并有应对措施与缓冲机制 |
| 不重复计算承诺 | 项目碳库未在其他碳汇项目、生态补偿或碳市场重复登记 |
| 审定核证资质合规 | 委托的审定核证机构具备相应资质且与项目无利益冲突 |
